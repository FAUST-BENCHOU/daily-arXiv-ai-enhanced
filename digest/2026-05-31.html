一、三篇论文方向与六个创新点

论文方向一：LLM 推理与部署效率优化

拟定论文题目： 面向低比特量化与约束解码的 LLM 推理效率协同优化方法

论文核心问题： 如何通过量化生成质量提升与约束解码搜索空间压缩的协同设计，在保证输出质量的前提下显著降低 LLM 推理的端到端延迟与资源开销。

创新点一：Logit 感知的最终块量化方法

大多数现有低比特权重量化方法采用逐块均方误差（MSE）优化，忽略了未嵌入层（LM head）在块优化中的缺失，导致量化模型在生成任务（尤其是长响应和思维链）中的 token 概率分布与全精度模型严重偏离 5717。少数现有方法尝试在量化后对输出分布进行校准，但通常需要额外的后处理步骤或引入额外的推理开销，且未能从根本上解决最终 Transformer 块量化误差对生成质量的级联放大效应 12227。为此，本文提出 Logit 感知的最终块量化方法（LFQ），通过最小化量化模型与全精度模型在最终 logit 上的交叉熵损失来量化最后一个 Transformer 块，从而在无需额外推理步骤的前提下显著提升低比特量化模型的生成质量 7。

  • 创新类型： 方法设计创新
  • 创新性判断： 该创新点针对现有逐块 PTQ 方法在生成任务上的质量退化问题，提出了一个简单但有效的改进方案，与池内文献 5717 形成明确对比，且与 12227 的现有方法互补，具有明确的创新定位。

创新点二：基于 Token 空间压缩的约束解码加速方法

大多数现有 CFG 约束解码引擎在每一步都需要在完整词表上进行搜索，导致复杂 CFG 下的开销极高，严重限制了约束解码在实际场景中的可扩展性 71722。少数现有方法通过投机解码或草稿模型加速生成过程，但这些方法通常需要额外的模型训练或复杂的并行验证机制，且与约束解码的搜索空间问题正交 52730。为此，本文提出 CFGzip，一种离线压缩 token 搜索空间的技术，通过预计算给定 CFG 下每个位置的有效 token 集合，将搜索空间从完整词表压缩到仅包含合法 token 的子集，从而在不牺牲约束精度的前提下实现最高两个数量级的延迟降低 17。

  • 创新类型： 方法设计创新
  • 创新性判断： 该创新点直接针对约束解码的核心瓶颈——搜索空间过大，提出了一个与现有投机解码、草稿模型等方法正交的离线压缩方案，与池内文献 71722 形成明确对比，且与 52730 的现有方法互补。

论文方向二：AI Agent 安全、对齐与鲁棒性

拟定论文题目： 面向开放环境 AI Agent 的轻量级安全对齐与鲁棒性增强方法

论文核心问题： 如何在保持 Agent 执行能力的前提下，通过轻量级对齐框架和鲁棒性训练方法，有效防御干扰指令攻击和元数据篡改风险。

创新点三：基于元数据隔离的 Agent 安全治理架构

大多数现有 AI Agent 安全框架依赖 Agent 自身对安全策略的理解和执行，但 Agent 容易受到幻觉、误解和对抗性操纵的影响，无法可靠地解释或传播安全关键的元数据（如访问策略、数据分类和行为约束）141529。少数现有方法尝试通过提示工程或微调来增强 Agent 的安全意识，但这些方法无法从根本上解决 Agent 在读取和写入路径上处理安全元数据时的不可靠性问题 242830。为此，本文提出基于带外元数据通道的 Agent 安全治理架构（Redpanda ADP），通过独立于 Agent 读写路径的基础设施通道来承载安全上下文、策略信号和审计轨迹，在 Agent 生命周期的每个阶段（数据访问范围限定、行动约束、事后审计）强制执行治理规则 14。

  • 创新类型： 系统框架创新
  • 创新性判断： 该创新点提出了一个与现有 Agent 安全方法（依赖 Agent 自身）完全不同的架构思路，通过基础设施级带外通道实现安全治理，与池内文献 141529 形成明确对比，且与 242830 的现有方法互补。

创新点四：基于过程奖励的逐步模型路由与鲁棒性增强

大多数现有 Agent 安全对齐方法使用结果奖励（仅反映最终答案正确性）来训练安全护栏或路由策略，无法评估中间推理步骤的安全性，导致在复杂开放环境中的泛化能力不足 131524。少数现有方法引入过程奖励或逐步监督，但通常依赖昂贵的 NLI 验证器或 LLM 评判器，难以在 RL 训练规模下高效部署，且对稀有实体事实的奖励信号不可靠 202129。为此，本文提出基于语料库接地过程奖励的逐步模型路由框架（RoRo），通过从 Wikipedia 共现统计中提取的轻量级过程奖励信号，结合基于评分卡（Rubric）的逐步路由策略，在无需外部验证器的情况下实现细粒度的安全对齐 1321。

  • 创新类型： 方法设计创新 + 约束处理创新
  • 创新性判断： 该创新点将过程奖励与逐步路由结合，并采用语料库接地的方式替代昂贵的神经验证器，与池内文献 131524 形成明确对比，且与 202129 的现有方法互补。

论文方向三：工具调用、知识图谱与结构化生成

拟定论文题目： 面向结构化环境的 LLM 工具表示迁移与知识图谱构建后校正方法

论文核心问题： 如何通过参数化工具表示和本体接地后校正，解决 LLM 在工具调用和知识图谱构建中的上下文开销过大和事实一致性不足问题。

创新点五：参数化工具表示的迁移学习方法

大多数现有工具调用方法依赖上下文学习（ICL），将详细的工具文档和使用示例直接放入上下文，导致推理开销随上下文长度增长而显著增加，并增加了幻觉风险 1912。少数现有方法通过微调来增强通用工具调用能力，但未能有效内化已见工具的具体细节，仍然依赖上下文文档 82830。为此，本文提出 ParaTool 框架，将每个工具投影到一组可加载的参数中，通过动态集成这些参数化工具，使 LLM 无需上下文文档或示例即可执行工具调用，并通过三阶段训练（参数化工具预训练、工具感知指令微调、工具偏好对齐）实现工具知识的有效内化 1。

  • 创新类型： 特征表示创新 + 泛化迁移创新
  • 创新性判断： 该创新点将工具表示从上下文转移到参数空间，从根本上改变了工具调用的实现范式，与池内文献 1912 形成明确对比，且与 82830 的现有方法互补。
