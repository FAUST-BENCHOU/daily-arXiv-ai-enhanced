论文方向一：LLM 推理服务中的去中心化缓存与路由机制

拟定论文题目： 面向分布式 LLM 推理的去中心化前缀缓存感知路由与弱一致性同步机制

论文核心问题： 在分布式 LLM 推理集群中，如何在不依赖集中协调器的情况下，高效地复用跨节点的前缀 KV 缓存，以降低推理延迟并提升系统吞吐量。

创新点一：去中心化缓存感知路由决策机制

大多数现有方法依赖集中式协调器或全局元数据服务来管理跨节点的 KV 缓存信息，导致单点瓶颈、协调开销大，且难以扩展到大规模集群 11928。少数现有方法尝试引入分布式哈希表或 gossip 协议来分散缓存元数据，但通常需要强一致性保证或频繁的全量同步，在网络延迟较高时路由决策的时效性反而下降 119。为此，本文提出一种基于局部基数树与异步反熵同步的去中心化路由机制，每个节点仅维护本地缓存索引，并通过周期性、轻量级的对等交换来估计远端缓存状态，请求被路由到最长估计前缀匹配的节点，无需集中协调或 KV 缓存传输。

  • 创新类型： 系统框架创新 + 方法设计创新
  • 创新性判断： 文献池中 1 提出了去中心化路由的初步思路，但未深入探讨弱一致性下的路由决策质量与网络开销的权衡。本文在此基础上，进一步形式化路由决策的置信度模型，并设计自适应同步频率策略，以在缓存命中率与通信开销之间取得更优平衡。

创新点二：弱一致性缓存元数据同步与路由质量保障

大多数现有缓存同步方法要求强一致性或最终一致性下的全量元数据交换，在网络分区或节点故障时容易导致路由决策严重滞后或缓存命中率骤降 11928。少数现有方法采用概率性同步或基于租约的缓存失效协议，但缺乏对路由决策质量的显式保障，无法在同步开销与决策准确性之间进行自适应权衡 119。为此，本文提出一种基于置信度感知的自适应同步机制，每个节点根据本地缓存变化率、网络延迟和请求到达模式动态调整同步频率，并引入路由决策的置信度阈值，仅在置信度低于阈值时触发同步，从而在保证路由质量的同时最小化同步开销。

  • 创新类型： 方法设计创新 + 约束处理创新
  • 创新性判断： 文献池中 1 的同步策略是固定周期的反熵，未考虑动态调整。本文提出的自适应同步机制，结合置信度阈值，是对去中心化缓存路由系统的重要补充，解决了弱一致性下的路由质量保障问题。

论文方向二：LLM 推理的混合注意力与稀疏计算架构优化

拟定论文题目： 面向 LLM 推理的可学习稀疏注意力分配与混合架构优化方法

论文核心问题： 如何通过可学习的方式，在 LLM 推理中自适应地分配全注意力和滑动窗口注意力，并优化稀疏计算模式，以在保持模型质量的同时降低计算和内存开销。

创新点三：基于 L0 正则化的可学习注意力稀疏分配机制

大多数现有混合注意力架构依赖手工规则或简单的后验启发式来分配全注意力（FA）和滑动窗口注意力（SWA），无法根据任务和数据分布自适应调整，导致计算资源浪费或长距离依赖捕获不足 82017。少数现有方法引入可学习的稀疏分配，但通常使用 Gumbel-Softmax 或直通估计器，训练不稳定且难以精确控制目标稀疏度 82。为此，本文提出基于 L0 正则化和增广拉格朗日约束的可学习注意力稀疏分配框架，为每个注意力单元（层或 KV 头）学习一个二进制掩码，在用户指定的稀疏度目标下，通过 L0 正则化鼓励稀疏性，并通过增广拉格朗日方法精确约束最终稀疏度，从而在训练过程中自动发现最优的 FA/SWA 分配模式。

  • 创新类型： 方法设计创新 + 约束处理创新
  • 创新性判断： 文献池中 8 提出了 ConSA 框架，使用 L0 正则化和增广拉格朗日约束，是本文的直接基础。本文在此基础上，进一步探索更细粒度的注意力单元（如单个注意力头）的分配，并研究不同稀疏度目标下的分配模式与模型性能的帕累托前沿。

创新点四：算子级稀疏计算与硬件友好型部署优化

大多数现有稀疏注意力方法在算法层面设计稀疏模式，但未充分考虑底层硬件（如 GPU、NPU、AIE）的计算特性，导致稀疏模式无法有效转化为实际的加速收益 8203。少数现有方法开始关注硬件感知的模型设计，但通常针对特定硬件平台进行手工优化，缺乏通用性和可迁移性 32122。为此，本文提出一种算子级稀疏计算优化框架，将学习到的注意力稀疏模式（FA/SWA 分配）映射为硬件友好的计算图变换，包括算子融合、内存访问模式优化和并行调度策略，并针对不同硬件平台（GPU、NPU）提供自动化的部署代码生成，确保稀疏模式在实际推理中带来可测量的性能提升。

  • 创新类型： 系统框架创新 + 方法设计创新
  • 创新性判断： 文献池中 3 针对 AIE 进行了手工映射，21 提出了 NPU 延迟预测器，但均未与可学习的稀疏分配结合。本文填补了从算法稀疏模式到硬件高效部署之间的鸿沟。

论文方向三：LLM 在线推理的配置选择与性能预测

拟定论文题目： 面向在线 LLM 服务的约束感知模型选择与无微架构先验的延迟预测方法

论文核心问题： 在在线 LLM 推理服务中，如何在不了解底层硬件微架构和编译器优化细节的情况下，准确预测推理延迟，并在资源预算和服务质量约束下，为每个请求动态选择最优的模型和配置。

创新点五：无微架构先验的 NPU 推理延迟预测方法

大多数现有 LLM 推理延迟预测方法依赖于对 GPU 微架构（如 CUDA core、memory hierarchy）的详细建模，或需要大量端到端测量数据来拟合经验模型，难以迁移到微架构未公开的商业 NPU 上 21322。少数现有方法尝试使用黑盒或灰盒建模，但通常无法捕捉由 bucketing 导致的延迟非线性，预测精度在输入输出长度变化时显著下降 216。为此，本文提出一种基于桶（bucket）级端到端测量的延迟预测方法，通过少量（每个桶两次）端到端测量来刻画每个桶的延迟特性，并通过组合这些桶级结果来预测任意输入输出长度组合的延迟，无需任何微架构或编译器信息，同时有效捕捉 bucketing 带来的非线性。
