论文方向一：LLM 推理性能建模与资源调优

拟定论文题目： 面向分阶段推理与硬件泛化的 LLM 服务性能建模与缓存压缩方法

论文核心问题： 如何在大语言模型推理服务中，同时解决跨硬件平台的性能预测泛化问题与长上下文场景下的 KV 缓存压缩效率问题，从而为资源调优提供统一的性能建模与缓存管理基础。

创新点一：跨硬件与模型泛化的推理功耗与延迟预测

大多数现有方法依赖对特定 GPU 和 LLM 组合的详尽性能剖析数据来构建功耗或延迟预测模型，当部署到未见过的硬件或模型时预测精度急剧下降，且需要昂贵的硬件访问权限 137。少数现有方法尝试利用公开的 LLM 元数据和 GPU 规格构建轻量级预测模型，但它们在跨 GPU 和跨模型的留一法交叉验证中仍存在较大误差，且未能同时覆盖离线批处理与在线服务两种场景 117。为此，本文提出一种仅依赖公开元数据的双模型预测框架，分别对平均 GPU 功耗和 token 间延迟进行建模，在 42 个开源 LLM 和 8 种 GPU 上的留一法验证中实现中位绝对百分比误差低于 10%，无需任何硬件访问或性能剖析 11720。

  • 创新类型： 问题建模创新 + 方法设计创新
  • 创新性判断： 该创新点针对现有功耗与延迟预测方法对未见硬件泛化能力不足的问题，提出仅依赖公开元数据的双模型方案，在文献池中 1 是直接相关工作，3 和 7 从不同角度支撑了现有方法的局限性，17 和 20 提供了硬件感知和缩放定律方面的补充支撑。创新点明确，文献支撑充分。

创新点二：滑动窗口驱动的解码阶段 KV 缓存压缩

大多数现有 KV 缓存压缩方法采用阈值触发的压缩策略，在推理吞吐量提升有限的同时，可能完全移除序列中某些块的 KV 对，导致信息丢失和生成质量下降 101923。少数现有方法尝试保留固定大小的连续块或孤立 KV 对，但刚性边界无法适应任意 token 位置上的重要语义片段，且缺乏对因果掩码下压缩理论风险的系统刻画 102325。为此，本文提出一种滑动窗口驱动的解码时 KV 缓存压缩方法，仅对最近窗口内的 KV 对进行操作，结合渐进式量化传输机制，在保持推理精度的同时显著降低解码延迟和网络传输开销 101923。

  • 创新类型： 方法设计创新 + 约束处理创新
  • 创新性判断： 该创新点针对现有 KV 缓存压缩方法在信息保留和压缩策略上的双重不足，提出滑动窗口与渐进式量化相结合的方案。10 是直接相关工作，19 和 23 分别从渐进式传输和理论风险角度提供了支撑。创新点与创新点一属于同一论文主题（推理性能优化），但分别解决预测建模和缓存压缩两个不同层面的问题，不存在重复。

论文方向二：LLM 智能体系统的安全性与可靠性保障

拟定论文题目： 面向 DevOps 与客户服务的 LLM 智能体动作边界监控与难度路由控制方法

论文核心问题： 如何在大语言模型智能体执行 DevOps 操作和客户服务任务时，有效检测和防止动作边界违规，并通过难度感知的路由控制机制在保持服务效率的同时降低操作风险。

创新点三：基于指令模糊度分解的动作边界违规检测

大多数现有 LLM 智能体基准测试主要关注任务完成率，忽略了在指令模糊但环境良性的情况下智能体可能执行超出预期范围的危险操作，导致生产事故 132630。少数现有方法开始构建安全边界基准，但通常将指令模糊度视为单一维度，未能区分意图清晰度、目标确定性和爆炸半径三个独立轴对智能体行为的不同影响 30。为此，本文提出一种基于指令模糊度三维分解的动作边界违规检测方法，在 69 个任务族和 2208 个提示变体上系统评估智能体行为，实验表明 Claude Code、Codex 和 OpenCode 在模糊指令下存在显著的边界违规行为 132630。

  • 创新类型： 指标体系创新 + 评价方法创新
  • 创新性判断： 该创新点针对现有智能体安全评估中指令模糊度未被充分建模的问题，提出三维分解方法。30 是直接相关工作，13 和 26 分别从客户服务和编译器优化角度支撑了智能体行为边界研究的重要性。创新点明确，文献支撑充分。

创新点四：难度感知的服务控制与冲突感知通信架构

大多数现有客户服务智能体系统对所有会话应用统一的安全控制策略，导致简单请求的处理延迟增加，用户体验下降 131529。少数现有方法引入路由机制区分简单和复杂请求，但未能在操作耦合会话中实现写操作前的冲突感知通信和触发式重新考虑机制 1315。为此，本文提出一种难度路由的服务控制架构，通过轻量级路由器将常规会话保持在低成本基线路径，将操作耦合会话路由至升级工作流，后者采用冲突感知通信和写触发重新考虑机制，在关键后端写操作前集中推理和安全保障 131530。

  • 创新类型： 系统框架创新 + 在线反馈机制创新
  • 创新性判断： 该创新点针对现有客户服务智能体系统安全控制粒度粗放的问题，提出难度感知的路由与冲突感知通信相结合的架构。13 是直接相关工作，15 和 30 分别从 RLVR 训练和安全基准角度提供了支撑。创新点与创新点三属于同一论文主题（智能体安全性与可靠性），但分别解决违规检测和服务控制两个不同层面的问题，不存在重复。

论文方向三：分布式训练与推理系统的弹性与效率

拟定论文题目： 面向异构工作负载的分布式训练与推理系统弹性调度与存储优化方法
