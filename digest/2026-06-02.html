论文方向一：LLM 推理效率与量化压缩的协同优化

拟定论文题目：面向低比特推理稳定性的量化-稀疏协同优化与精度恢复方法

论文核心问题：如何在极端低比特量化（2-4 bit）和动态稀疏训练中，解决因精度损失导致的推理不稳定、输出轨迹膨胀和训练震荡问题，实现高效的 LLM 推理与训练。

创新点一：低比特推理过程级失效建模与轻量级恢复机制

大多数现有方法将低比特量化的评估焦点放在最终答案准确率上，忽略了量化噪声对推理过程稳定性的破坏，例如导致重复循环、预算耗尽和未闭合推理段等过程级失效 11118。少数现有方法尝试通过混合精度或后处理恢复来缓解精度损失，但通常需要全局高精度回退或重计算，开销较大且无法针对过程级失效进行定向修复 1829。为此，本文提出一种基于过程级失效模式分类的轻量级恢复机制，通过检测推理轨迹中的重复循环和预算耗尽信号，触发局部高精度回退（如 FP16 规划）或循环救援操作，在不显著增加推理成本的前提下恢复推理稳定性。

  • 创新类型：方法设计创新 + 约束处理创新
  • 创新性判断：池内文献 18 明确指出了 2-bit 推理的过程级失效模式，但未将其系统化为可在线检测的失效分类体系；111 关注量化噪声本身而非过程稳定性。本文创新点在于将失效模式建模与轻量级恢复策略结合，填补了低比特推理稳定性控制的空白。

创新点二：动态稀疏训练中的优化稳定性保障与内存高效训练

大多数现有动态稀疏训练（DST）方法在拓扑更新后，新生长参数的优化器状态冷启动会导致梯度更新过大，引发训练震荡和损失尖峰 17。少数现有方法尝试通过梯度裁剪或学习率调度缓解此问题，但未从根本上解决新参数与已有参数之间的优化状态不一致性，且通常需要存储全参数优化器状态，内存开销较大 1729。为此，本文提出一种结合优化器预热与密度感知学习率缩放的稀疏训练框架，仅对活跃参数存储梯度和优化器状态，并通过理论分析证明其优化稳定性，实现内存高效的 LLM 稀疏预训练。

  • 创新类型：方法设计创新 + 性能预测创新
  • 创新性判断：池内文献 17 已提出 SMET 框架，但本文创新点在此基础上进一步引入优化器预热与密度感知学习率缩放的联合机制，并强调仅存储活跃参数状态的内存优势，与 17 的现有方案形成互补。

- 评价指标：推理准确率、轨迹长度、训练损失尖峰频率、内存占用、吞吐量
- 消融实验：分别验证过程级失效分类模块、优化器预热模块、密度感知学习率缩放模块的贡献

论文方向二：长上下文推理中的 KV 缓存管理与注意力机制改进

拟定论文题目：面向长上下文推理的 KV 缓存驱逐策略与线性注意力读取优化

论文核心问题：如何在长上下文推理中，通过改进 KV 缓存的驱逐策略和注意力机制的读取方式，突破内存瓶颈并提升语义连贯性。

创新点三：方向性偏差感知的 KV 缓存驱逐策略

大多数现有 KV 缓存驱逐方法通过最小化被驱逐 token 的残余注意力质量来保留关键信息，但忽略了被驱逐 token 集与保留 token 集之间的方向性偏差，导致即使残余质量很小，方向分布偏差也会放大为显著的输出误差 5。少数现有方法引入动量统计或基于重要性的驱逐策略，但未从方向性偏差的角度系统分析驱逐对输出分布的影响 53。为此，本文提出一种方向性偏差感知的 KV 缓存驱逐策略，通过维护被驱逐 token 集的紧凑动量统计（包括计数、键均值、值均值和键-值协方差），在驱逐过程中补偿方向性偏差，从而在固定缓存大小下提升长上下文推理的准确性。

  • 创新类型：问题建模创新 + 方法设计创新
  • 创新性判断：池内文献 5 提出的 MomentKV 已识别方向性偏差问题并提出了动量统计方案，但本文创新点在此基础上进一步将方向性偏差建模为可在线补偿的优化目标，而非仅作为驱逐后的被动统计，与 5 形成差异化。

创新点四：曲率条件化的线性注意力读取压缩

大多数现有线性注意力方法通过门控、增量更新或核特征图优化写入端，但读取步骤保持不变：每个过去键都对输出有加性贡献，导致有用目标被大量存储向量稀释 27。少数现有方法尝试通过查询压缩或选择性读取来缓解此问题，但通常需要额外的学习参数或复杂的注意力掩码，且未利用 softmax 的几何特性 2724。为此，本文提出一种曲率条件化查询（CCQ）机制，通过二阶泰勒展开近似 softmax 对数配分函数，利用运行键协方差构造局部二次模型，在读取前沿高密度方向压缩查询，从而在不改变写入端的前提下提升线性注意力的检索能力。

  • 创新类型：方法设计创新 + 特征表示创新
  • 创新性判断：池内文献 27 已提出 CCQ 机制，但本文创新点在此基础上进一步将其与 KV 缓存驱逐策略（创新点三）结合，形成“驱逐-读取”联合优化框架，并强调 CCQ 作为读取端优化与驱逐端优化的互补性。

- 消融实验：分别验证方向性偏差补偿模块、CCQ 读取压缩模块、以及两者联合优化的效果

论文方向三：多智能体编排与在线服务系统的可观测性与资源调度

拟定论文题目：面向多智能体 LLM 系统的可观测性框架与动态资源调度方法

论文核心问题：如何在多智能体 LLM 系统中，通过可观测性框架诊断计算浪费，并基于负载预测实现高效的资源调度与能耗优化。

创新点五：多智能体 LLM 系统的失效感知可观测性框架

大多数现有 LLM 系统评估方法仅关注最终答案的准确性，无法揭示推理轨迹中计算浪费的发生点和失效模式，导致难以定位系统瓶颈 26。少数现有方法引入可观测性框架或轨迹分析，但通常面向单智能体或简单工具调用场景，缺乏对多智能体协作中特有的失效模式（如工具可靠性、执行恢复、编排循环、证据可用性等）的系统性映射和在线信号提取 2619。为此，本文提出一种失效感知的可观测性框架，将多智能体 LLM 系统中的重复失效模式映射为在线可追踪信号，包括工具可靠性、执行恢复、编排循环、证据可用性和预算压力等维度，并通过实例化在三智能体问答系统中验证其诊断能力。

  • 创新类型：指标体系创新 + 评价方法创新
  • 创新性判断：池内文献 26 已提出类似的失效感知可观测性框架，但本文创新点在此基础上进一步将其扩展为可泛化的失效模式分类体系，并强调在线信号提取与实时诊断能力，与 26 的离线分析形成差异。
