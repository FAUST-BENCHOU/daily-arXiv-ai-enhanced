今日三个主题

主题 1
长上下文与稀疏注意力推理效率
围绕 LLM 长上下文推理中位置编码耗尽、KV 缓存膨胀与稀疏注意力精度下降等核心瓶颈，探索周期性位置编码（P-RoPE）、递归增强注意力（RAT+）及通用 top-k 稀疏注意力框架（UNIQUE）等创新方案，以突破上下文窗口限制并提升推理效率。
主题 2
LLM 推理部署的资源管理与系统优化
聚焦离线与在线 LLM 推理部署中的资源效率问题，涵盖面向边缘生成推理的可演化资源管理智能体（E³-Agent）、内存高效的数据并行范式（SiDP）以及将零阶微调重构为推理负载的执行路径优化，旨在降低部署成本并提升吞吐。
主题 3
Agent 系统的可靠性、安全性与可行性评估
针对 LLM Agent 在工具使用、多步规划与持续服务中的可靠性挑战，研究批量条件下的拒绝鲁棒性测试协议、工具可行性感知评估（FeasiGen）以及结构化规划基准（DisasterBench），以提升 Agent 系统的安全边界与执行可信度。

一、三篇论文方向与六个创新点

论文方向一：长上下文与稀疏注意力推理效率

拟定论文题目： 面向长上下文LLM推理的周期性位置编码与递归增强稀疏注意力方法

论文核心问题： 如何突破LLM在超长上下文推理中因位置编码耗尽和KV缓存膨胀导致的性能瓶颈，同时保持稀疏注意力下的精度。

创新点一：周期性位置编码与滑动窗口协同机制

大多数现有方法依赖RoPE等绝对或相对位置编码，当序列长度超出预训练范围时，位置编码耗尽导致模型性能急剧下降 [1, 16, 18]。少数现有方法尝试通过扩展上下文窗口或引入稀疏注意力来缓解，但通常需要昂贵的继续预训练或复杂的架构改动，且难以真正支持无限上下文 [1, 12, 18]。为此，本文提出周期性RoPE（P-RoPE）与滑动窗口注意力（SWA）协同机制，通过周期性重置位置编码避免耗尽，同时利用SWA捕获局部依赖，再以无位置编码的全局注意力层实现跨序列的无界交互，理论上支持无限上下文窗口 1。

  • 创新类型： 问题建模创新 + 方法设计创新
  • 创新性判断： 池内文献 1 直接提出P-RoPE，但未充分讨论其与多种稀疏注意力框架的兼容性；16 和 18 分别提出通用稀疏注意力和递归增强注意力，但均未解决位置编码耗尽问题。本文创新点在于将P-RoPE与滑动窗口及全局NoPE层结合，形成统一的无限上下文推理框架。

创新点二：递归增强的查询感知稀疏注意力框架

大多数现有稀疏注意力方法（如Quest、MoBA、SnapKV）依赖静态或启发式的重要性估计，在长上下文场景下精度损失显著 [16, 18, 20]。少数现有方法引入递归增强注意力（如RAT+）来改善查询感知的稀疏推理，但递归记忆的衰减机制与稀疏预算的协同尚未被充分探索，导致在极端稀疏率下仍存在关键信息丢失 [18, 1, 16]。为此，本文提出递归增强的查询感知稀疏注意力框架，将指数衰减记忆模块嵌入top-k稀疏注意力中，通过记忆模块保留历史上下文的关键信息，弥补稀疏采样带来的信息损失，同时利用查询感知的页级重要性评分实现高效KV缓存加载 [18, 16]。

  • 创新类型： 方法设计创新 + 性能预测创新
  • 创新性判断： 池内文献 18 验证了RAT+对Quest、MoBA、SnapKV的改进，但未提出统一的框架；16 的UNIQUE框架虽通用，但未结合递归记忆。本文创新点在于将递归增强记忆与通用top-k稀疏注意力框架结合，形成统一的递归增强稀疏注意力方案。

建议实验设计：
- 对比方法： 标准RoPE + 全注意力、P-RoPE + 全注意力、标准RoPE + UNIQUE、标准RoPE + RAT+
- 实验数据或场景： Needle-in-a-Haystack任务、长文档问答、多轮对话
- 评价指标： 准确率、KV缓存大小、推理延迟、上下文窗口上限
- 消融实验： 滑动窗口大小、递归记忆衰减率、稀疏预算比例

论文方向二：LLM推理部署的资源管理与系统优化

拟定论文题目： 面向离线与在线LLM推理部署的内存高效数据并行与自适应资源管理方法

论文核心问题： 如何在离线批处理和在线服务场景下，通过内存优化和自适应调度降低LLM推理部署成本并提升吞吐。

创新点三：权重即服务的分布式内存共享数据并行范式

大多数现有数据并行（DP）方法在每块GPU上复制完整模型权重，导致显存被权重大量占用，留给KV缓存的空间有限，限制了批处理大小 [19, 21, 22]。少数现有方法引入模型并行（MP）来减少单设备权重，但MP需要细粒度同步，破坏了DP的独立性和调度灵活性 [19, 29, 8]。为此，本文提出SiDP，一种将权重视为带宽支持的共享资源的数据并行范式：通过权重即服务（WaS）模式，在NVLink上按需流式传输远程权重到本地缓存，同时结合缓存感知的批处理调度，在保持DP调度灵活性的同时大幅提升有效KV缓存容量 19。

  • 创新类型： 方法设计创新 + 系统框架创新
  • 创新性判断： 池内文献 19 直接提出SiDP，但未充分讨论其与在线推理场景的适配；21 和 8 分别关注边缘推理和ZO微调，但未解决DP的显存瓶颈。本文创新点在于将SiDP的WaS模式与在线负载预测结合，形成统一的离线/在线推理优化方案。

创新点四：事件驱动的在线自适应资源管理智能体

大多数现有资源管理系统依赖离线调优或固定策略，在非平稳负载（如用户驱动的语义事件、后台负载波动、设备变更）下性能迅速退化 [21, 6, 22]。少数现有方法引入在线学习或自适应机制，但通常需要大量在线数据或复杂的模型重训练，难以在毫秒级决策窗口内响应 [21, 6, 26]。为此，本文提出事件驱动的在线自适应资源管理智能体，将快速路径路由器（毫秒级调度）与慢路径LLM元控制器（事件驱动重配置）分离，通过工具接口暴露风险门控、路由器配置和性能校准等控制面，实现从执行反馈中持续学习并适应未知时变的服务时间映射 [21, 6]。

  • 创新类型： 系统框架创新 + 在线反馈机制创新
  • 创新性判断： 池内文献 21 提出$E^3$-Agent，但未详细讨论其与SiDP等内存优化技术的协同；6 提出层次化提示域控制，但聚焦于Agent自身而非资源管理。本文创新点在于将事件驱动的自适应资源管理与内存高效数据并行结合，形成统一的在线推理优化系统。

论文方向三：Agent系统的可靠性、安全性与可行性评估

拟定论文题目： 面向LLM Agent的批量条件鲁棒性测试与工具可行性感知评估方法

论文核心问题： 如何系统性地评估和提升LLM Agent在工具使用、多步规划和批量服务中的可靠性、安全性与可行性。

创新点五：批量条件驱动的拒绝鲁棒性配对测试协议
