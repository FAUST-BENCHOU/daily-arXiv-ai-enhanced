论文方向一：面向多智能体与长上下文推理的 KV 缓存管理与状态复制

拟定论文题目： 面向多智能体工作流与长上下文推理的分布式 KV 缓存编排与信念级状态复制方法

论文核心问题： 在多智能体系统和长上下文推理场景中，如何通过分布式 KV 缓存管理和非比特级的状态复制，减少重复计算、降低显存开销并提升推理效率。

创新点一：零拷贝分布式 KV 缓存编排与上下文复用

大多数现有方法将 KV 缓存管理局限于单机推理服务，在多智能体工作流中，每个智能体需要重复计算共享上下文的预填充阶段，导致大量冗余计算和显存浪费 1415。少数现有方法尝试通过 KV 缓存共享或压缩来减少重复计算，但通常受限于本地服务范围，缺乏跨智能体的分布式编排能力，且压缩方法在重尾数据分布下性能不稳定 152225。为此，本文提出基于通信感知图的零拷贝分布式 KV 缓存编排框架，将 KV 缓存作为分布式系统的一等公民，提供物化、传输、分叉、组合和驱逐等操作原语，使多智能体能够在不重新计算的情况下复用长上下文，从而显著降低首 Token 延迟和多智能体计算成本 11429。

  • 创新类型： 系统框架创新 + 方法设计创新
  • 创新性判断： 文献池中 AAFLOW+ 1 提出了零拷贝分布式 KV 缓存编排的初步思路，但尚未将其与多智能体工作流的通用状态复制机制结合。本文在此基础上，进一步引入信念级状态复制 14 的思想，将 KV 缓存视为分布式共享状态，实现跨智能体的高效上下文复用。

创新点二：信念级状态复制与上下文压缩

大多数现有分布式系统中的状态复制方法基于确定性状态机复制模型，要求副本执行确定性转换以产生一致的比特级状态，这在包含随机生成模型的智能体系统中会导致执行灵活性下降和上下文遗忘 14115。少数现有方法尝试通过语义等价而非比特一致来放松复制约束，但缺乏对智能体推理过程中上下文压缩与选择性保留的系统性支持 52714。为此，本文提出信念级状态复制机制，将副本的节点状态形式化为知识可见性而非数据可见性，并结合结构化上下文压缩方法，在保留推理结论的同时剪枝探索性工作，实现上下文的高效复用与存储 51427。

  • 创新类型： 问题建模创新 + 方法设计创新
  • 创新性判断： 文献池中 ESR 14 提出了信念级状态复制的理论框架，但未与具体的 KV 缓存管理和上下文压缩方法结合。Structured Thoughts 5 提出了上下文剪枝方法，但未将其应用于分布式状态复制场景。本文创新性地将两者结合，在信念级复制框架下实现上下文的高效压缩与复用。

论文方向二：面向 LLM 推理与部署的资源感知优化与配置调优

拟定论文题目： 面向 MoE 推理与分布式数据处理的资源感知性能建模与配置优化方法

论文核心问题： 在 MoE 大模型推理和分布式数据处理系统中，如何通过资源感知的性能建模和配置优化，在满足性能约束的同时最小化资源成本。

创新点三：压力感知的热专家驻留映射与资源建模

大多数现有 MoE 推理优化方法主要关注减少 Token 移动，忽略了专家热度偏斜导致的计算、通信、内存带宽和队列压力等多维资源瓶颈 103029。少数现有方法引入专家复制或动态放置策略，但通常仅考虑单一资源维度（如通信开销），缺乏对多维度资源压力的联合建模与动态平衡 10221。为此，本文提出压力感知的热专家驻留映射框架，基于专家热度、权重加载成本、迁移开销和运行时资源压力，动态决定专家的提升、保留、降级或驱逐策略，并将路由 Token 组映射到合适的驻留副本，从而联合缓解通信、内存和队列瓶颈 103029。

  • 创新类型： 问题建模创新 + 方法设计创新
  • 创新性判断： 文献池中 HCRMap 10 提出了压力感知的专家驻留映射，但主要针对 3.5D 多芯片系统，未将其泛化到通用 MoE 推理场景。UMoE 30 提出了专家池重对齐方法，但未涉及运行时资源压力建模。本文在此基础上，构建通用的多维资源压力模型，并设计动态专家驻留映射策略。

创新点四：阶段级资源分配与成本-性能权衡优化

大多数现有分布式数据处理系统的资源分配方法在应用级别进行，忽略了同一应用中不同阶段在计算特征、数据规模和资源需求上的巨大差异，导致资源分配次优 24316。少数现有方法引入阶段级或任务级资源分配，但通常不支持用户指定的成本-性能权衡偏好，且难以处理资源分配与执行时间之间的非线性关系 2438。为此，本文提出阶段级执行器分配方法，通过训练树集成模型估计阶段运行时间和成本与资源分配的函数关系，并基于用户指定的成本-性能权衡偏好，为每个阶段独立推荐最优资源分配方案 2438。

  • 创新类型： 方法设计创新 + 优化求解创新
  • 创新性判断： 文献池中 24 提出了阶段级执行器分配方法，但主要针对 Apache Spark 环境。本文将其扩展到更通用的分布式推理和数据处理场景，并结合 MoE 推理的资源特征进行适配。

创新点五：异构智能体队列与运行时约束记忆的安全探索

大多数现有方法通过静态安全指令或单一模型约束 Agent 行为，导致探索范围受限或安全违规频发 2918。少数现有方法引入多智能体辩论或角色分离机制，但通常缺乏对探索过程中失败经验的系统化积累和复用，导致重复违规和 Token 浪费 22818。为此，本文提出异构智能体队列框架，通过分离创造性探索（Disrupter）、运行时约束检查（Validator）和类比推理（Broker）三个角色，并将失败经验通过蒙特卡洛树搜索编译为紧凑的签名约束补丁（Scars），实现失败经验的本地缓存和跨队列继承，从而在保证安全性的同时提升探索效率 22818。

  • 创新类型： 系统框架创新 + 在线反馈机制创新
