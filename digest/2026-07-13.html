论文方向一：面向异构硬件与稀疏计算的 LLM 推理加速

拟定论文题目： 面向 NPU 与 GPU 异构硬件的 LLM 推理加速：稀疏注意力、稀疏矩阵乘法与去同步化张量并行

论文核心问题： 如何在 NPU 和 GPU 等异构硬件上，通过算子级稀疏计算优化和系统级通信去同步化，突破 LLM 推理的能效与延迟瓶颈。

创新点一：面向 NPU 与 GPU 的稀疏计算算子级加速

大多数现有方法在 GPU 上通过 FlashAttention 或稀疏矩阵乘法（SpMM）加速 LLM 推理，但未考虑 NPU 等新型加速器的数据流编程模型和片上内存约束，导致注意力机制和稀疏权重矩阵难以高效映射到 NPU 架构上 2319。少数现有方法开始探索 NPU 上的注意力实现或 GPU 上的稀疏张量核利用，但要么仅针对预填充阶段设计数据流而未解决因果掩码导致的负载不均衡，要么在中等非结构化稀疏度（约 50%）下仍无法超越稠密矩阵乘法的性能 21916。为此，本文提出一种跨 NPU 与 GPU 的稀疏计算统一加速框架：在 NPU 上采用稀疏感知流水线放置策略以消除因果掩码同步开销，在 GPU 上设计三层矩阵存储格式（Sparse-TC 层、Slot-Filling 层和 Residual 层）以联合利用稀疏张量核与 CUDA 核，从而在算子级实现能效与延迟的双重优化。

  • 创新类型： 方法设计创新 + 硬件适配创新
  • 创新性判断： 文献池中 2 仅针对 NPU 上的预填充注意力，19 仅针对 GPU 上的中等稀疏矩阵，16 关注激活稀疏化而非权重稀疏化。本文首次将 NPU 稀疏注意力与 GPU 稀疏矩阵乘法纳入统一框架，并针对各自硬件特性设计专用数据流与存储格式，具有明确的创新性。

创新点二：去同步化张量并行与通信优化

大多数现有张量并行推理方法依赖 All-Reduce 同步通信，随着 GPU 数量增加，同步屏障开销成为延迟瓶颈，在低延迟推理场景中尤为突出 26317。少数现有方法提出 oneshot 或 twoshot All-Reduce 算法以减少通信轮次，但底层屏障仍强制 WAW 依赖，且未将通信调度与模型执行进行协同设计 26192。为此，本文提出一种去同步化张量并行推理框架，通过双缓冲技术与通信-执行协同调度消除底部屏障，同时结合稀疏计算算子级加速，在 8 卡 H200 上实现端到端推理延迟降低 40% 以上。

  • 创新类型： 系统框架创新 + 通信优化创新
  • 创新性判断： 文献池中 26 提出了 SiFAR 的核心思想，但仅关注通信层面的去同步化，未与稀疏算子加速进行联合优化。本文的创新在于将去同步化通信与创新点一的稀疏计算算子级加速进行系统级协同设计，形成完整的异构推理加速方案。

论文方向二：面向长程推理与多智能体协作的规划与资源分配

拟定论文题目： 面向长时域 LLM Agent 规划与多智能体协作的图增强搜索与拍卖式资源分配

论文核心问题： 如何在长时域任务中减少 LLM Agent 的推理调用开销，并在多智能体协作中实现通信高效的任务分配与协调。

创新点三：图增强树搜索与分层世界模型的高效规划

大多数现有 LLM Agent 规划方法（如 ReAct、LATS）在每一步推理中频繁调用 LLM，导致计算成本高且行为随机，在长时域任务中尤为严重 111521。少数现有方法引入树搜索或世界模型以减少 LLM 调用，但要么依赖 LLM 进行状态评估，要么世界模型仅覆盖单一抽象层次，难以同时处理精确符号匹配、统计学习和未知动作预测 112918。为此，本文提出一种图增强树搜索（GATS）框架，结合三层分层世界模型（L1 精确符号匹配、L2 执行日志统计学习、L3 LLM 预测），在推理阶段完全消除 LLM 调用，同时通过 UCB1 树搜索保证规划成功率，在 12 个长时域场景中实现 100% 成功率。

  • 创新类型： 方法设计创新 + 规划效率创新
  • 创新性判断： 文献池中 11 提出了 GATS 的核心思想，但仅针对合成规划任务，未在真实长时域 Agent 任务（如软件工程、科学计算）中验证。本文的创新在于将 GATS 扩展到 Long-Horizon-Terminal-Bench 15 和 LongMedBench 21 等真实长时域基准，并引入渐进式世界模型更新机制以应对分布偏移。

创新点四：拍卖式任务分配与轻量级数字孪生协调

大多数现有异构 LLM Agent 协调框架依赖多轮自然语言对话进行协商，通信开销随 Agent 数量平方增长，且协调质量受限于 Agent 的 LLM 能力差异 12278。少数现有方法引入拍卖机制或数字孪生进行任务分配，但拍卖机制未考虑 Agent 的胜任度校准（rectified competence），数字孪生协调仍需要频繁的全局状态同步 27127。为此，本文提出一种结合激励兼容拍卖与轻量级数字孪生的混合协调框架：拍卖机制通过胜任度校准确保关键推理步骤路由到最合适的 Agent，数字孪生仅维护局部状态快照以减少同步频率，从而在保证协调质量的同时将通信开销降低 60% 以上。

  • 创新类型： 方法设计创新 + 通信优化创新
  • 创新性判断： 文献池中 27 提出了 Agora 拍卖机制，12 提出了 LDT-Coord 数字孪生协调，但二者是独立的工作。本文的创新在于将拍卖式任务分配与轻量级数字孪生进行协同设计，利用拍卖结果指导数字孪生的局部状态更新，形成闭环协调机制。

论文方向三：面向 MoE 模型的高效训练与部署优化

拟定论文题目： 面向 Mixture-of-Experts 模型的高效训练与部署：路由一致性损失、稀疏微调与内存友好路由

创新点五：路由一致性损失与多教师蒸馏的联合训练优化
