三篇论文方向与六个创新点

论文方向一：面向长程与多步推理的智能体记忆与技能管理

拟定论文题目： 超越语义相似性：面向长程智能体的执行状态感知记忆与技能知识注入方法

论文核心问题： 现有智能体记忆系统主要依赖语义相似性进行检索，难以捕捉跨会话的执行状态依赖关系，且技能知识以明文形式注入上下文导致高昂的预填充开销，如何设计兼顾状态追踪与高效知识注入的记忆管理机制是该方向的核心挑战。

创新点一：执行状态感知的层次化记忆管理

大多数现有方法将智能体历史交互组织为扁平化的语义片段，通过向量相似性检索相关内容，这种方式会打碎决策轨迹并混合有效与错误轨迹，导致状态重构困难且错误难以隔离 6912。少数现有方法开始引入结构化记忆或状态树，但通常依赖固定的上下文窗口或简单的摘要策略，在长程任务中难以同时控制上下文增长与保持状态连贯性 1520。为此，本文提出执行状态感知的层次化记忆管理框架，将交互历史组织为状态树，通过子目标摘要、近期轨迹与分支提示的组合推导当前状态，并设计增长、压缩、维护与修正四种操作来动态管理树结构，以在上下文预算内保持状态连贯性。

  • 创新类型： 问题建模创新 + 方法设计创新
  • 创新性判断： 文献池中 12 提出了 MAGE 的执行状态树思想，但未解决跨会话持久化与技能知识注入的耦合问题；6 和 9 关注持久化记忆但依赖语义检索。本文创新点将状态树管理与技能注入统一建模，与池内现有方法形成互补。

创新点二：技能知识的权重空间注入与模块化组合

大多数现有方法将技能知识以文本形式注入智能体提示，每次推理都需要加载完整的技能描述，导致预填充阶段 token 开销巨大且技能内容以明文暴露 102023。少数现有方法尝试将技能编码为低秩适配器（LoRA）以消除上下文开销，但现有方案依赖预训练的超网络，无法在推理过程中根据任务需求动态组合或更新技能模块 1030。为此，本文提出基于在线蒸馏的技能知识注入方法，将执行状态树中积累的技能知识在线蒸馏为轻量 LoRA 模块，支持模块化加载、缩放与组合，在消除技能 token 开销的同时保持知识注入的灵活性与可更新性。

  • 创新类型： 方法设计创新 + 泛化迁移创新
  • 创新性判断： 10 的 LatentSkill 将技能转换为 LoRA 但依赖预训练超网络，无法在线更新；20 的 RHO 利用轨迹优化但技能仍以文本形式存在。本文创新点将状态树积累的技能在线蒸馏为可组合 LoRA，与池内方法形成差异化。

论文方向二：大语言模型推理服务与部署的系统级优化

拟定论文题目： 面向长上下文推理服务的头感知 KV 缓存管理与 SLO 感知调度方法

论文核心问题： 长上下文推理场景中 KV 缓存成为显存与服务并发度的主要瓶颈，现有系统将 KV 缓存视为同质化序列进行管理，忽略了不同注意力头在功能角色与运行时重要性上的结构化差异，且缺乏细粒度的服务质量（SLO）感知调度能力。

创新点三：头感知的 KV 缓存结构化压缩与复用

大多数现有方法将 KV 缓存视为同质的 token 级内存块，对所有注意力头采用相同的缓存策略，导致显存利用率低且缓存复用效率受限 81421。少数现有方法开始关注注意力头的差异化行为，但通常仅针对特定场景（如长上下文或前缀缓存）进行优化，缺乏统一的头感知缓存管理框架 1426。为此，本文提出头感知的 KV 缓存管理系统，根据注意力头的功能角色（如局部注意力头 vs. 全局注意力头）、注意力距离分布与运行时重要性，为不同头分配差异化的缓存策略（如选择性丢弃、压缩或完整保留），以在显存约束下最大化缓存复用率。

  • 创新类型： 问题建模创新 + 方法设计创新
  • 创新性判断： 14 的 RedKnot 提出了头感知 KV 缓存管理，但主要关注长上下文场景；8 的 Vortex 支持稀疏注意力但未涉及头差异化缓存。本文创新点将头感知策略扩展到通用推理服务场景，并与 SLO 感知调度结合。

创新点四：SLO 感知的滑动窗口批处理调度

大多数现有推理调度系统依赖粗粒度的输出约束或固定批处理策略，难以在请求间资源竞争下同时保证高吞吐与细粒度服务质量（SLO）差异化 111421。少数现有方法引入 SLO 感知调度或动态分块，但通常需要精确的批处理时延预测模型，且在多优先级请求共存时难以平衡公平性与效率 1126。为此，本文提出基于轻量级批处理时延预测器的滑动窗口调度方法，通过结合当前迭代与下一次迭代的信息实现动态分块，并引入多级优先级排序器在公平性与效率之间进行权衡，以在严格 SLO 保证下提升系统吞吐。

  • 创新类型： 方法设计创新 + 约束处理创新
  • 创新性判断： 11 的 SlidingServe 提出了滑动窗口 SLO 感知调度，但未与头感知缓存管理集成；14 和 21 关注缓存优化但未涉及 SLO 调度。本文创新点将 SLO 感知调度与头感知缓存管理统一建模，形成端到端优化。

论文方向三：面向黑盒与受限场景的智能体训练与调优方法

拟定论文题目： 面向黑盒智能体与稀缺标注场景的测试时优化与自监督轨迹偏好学习方法

论文核心问题： 当智能体为 API 级黑盒模型或标注数据稀缺时，参数级优化方法不可用，现有测试时方法通常依赖大量计算资源或无法有效利用轨迹反馈，如何设计无需参数更新的高效测试时优化与自监督学习方法是该方向的核心挑战。

创新点五：基于序贯蒙特卡洛的黑盒智能体测试时策略采样

大多数现有方法对黑盒智能体只能通过提示工程或固定策略进行控制，无法进行参数级优化，导致在复杂任务中性能受限 51628。少数现有方法尝试利用强化学习与贝叶斯推断的等价性，通过后验采样来模拟最优策略，但现有方案通常需要大量采样或依赖精确的奖励模型，在奖励稀疏或计算预算有限时效率低下 2829。为此，本文提出基于序贯蒙特卡洛（SMC）的黑盒智能体测试时优化方法，通过学习值函数引导采样过程，在保持底层黑盒模型不变的情况下，从最优策略的后验分布中高效采样，以在有限计算预算下提升任务成功率。

  • 创新类型： 方法设计创新 + 约束处理创新
  • 创新性判断： 28 的 AMC 提出了基于 SMC 的黑盒智能体优化，但未解决采样效率与奖励稀疏问题；5 的 TTT-RTL 在测试时训练但需要 EDA 反馈。本文创新点将自适应采样分配与 SMC 结合，提升计算效率。
