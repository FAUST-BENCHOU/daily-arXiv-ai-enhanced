论文方向一：大语言模型推理加速与视觉/扩散/缓存压缩

拟定论文题目： 面向多模态与扩散架构的训练无关推理加速：从视觉 Token 剪枝到动态缓存与并行解码的统一框架

论文核心问题： 如何在不引入额外训练开销的前提下，针对多模态大语言模型（MLLM）和扩散语言模型（dLLM）的推理瓶颈，设计模型无关的加速方法，同时兼顾视觉 Token 冗余、KV Cache 动态分配与并行解码策略。

创新点一：信息论驱动的视觉 Token 剪枝与扩散模型动态缓存协同优化

大多数现有方法在处理 MLLM 的视觉 Token 冗余时，要么依赖注意力分数保留高注意力 Token，要么基于多样性准则保留代表性 Token，但前者容易保留冗余 Token，后者则对用户指令不敏感，且两者均缺乏对剪枝目标的原理性建模 11617。少数现有方法尝试结合多种准则或引入缓存-预测机制来加速扩散模型，但扩散模型中的离散外推操作与连续扩散轨迹存在错位，导致高加速比下质量严重下降，且静态缓存策略无法适应 Token 属性在层间和解码步间的动态变化 1617。为此，本文提出一种信息论驱动的协同加速框架，在 MLLM 端基于 Token 最优保留集构建原则（任务相关性、信息覆盖、语义多样性）进行训练无关的视觉 Token 剪枝 1，同时在扩散语言模型端引入动态缓存更新机制，根据层间 Token 动态自适应分配缓存预算，并配合自适应并行解码阈值校准，以平衡生成质量与效率 17。

  • 创新类型： 方法设计创新 + 约束处理创新
  • 创新性判断： 现有方法 1 仅关注视觉 Token 剪枝，16 仅关注扩散模型的宏轨迹外推，17 仅关注 dLLM 的缓存与解码。本文首次将两者纳入统一框架，并利用信息论原理解决剪枝目标定义不清的问题，同时用动态策略解决缓存分配僵化的问题，具有明确的互补性和新颖性。

创新点二：基于前向信息熵的 KV Cache 压缩与块并行推测解码的联合优化

大多数现有 KV Cache 压缩方法主要依赖注意力权重来估计 Token 重要性，虽然能有效捕捉上下文相关性，但忽略了与预测不确定性和 Token 信息量相关的互补信息论信号 281118。少数现有方法开始引入信息论指标或推测解码来提升推理效率，但推测解码在扩散模型等非自回归架构中面临特征错配问题，且现有压缩方法未将 Token 的前向影响（即压缩 Token 对未来上下文的影响）纳入考量 121728。为此，本文提出一种联合优化框架，在 KV Cache 压缩端引入“前向影响”度量，结合 Token 级预测不确定性与层间表示熵，选择对远距离未来上下文影响更大的 Token 进行保留 28；在解码端，针对多超连接（MHC）等新型架构，采用预折叠残差状态作为条件信号，并引入轻量级门控残差压缩器替代通用线性压缩器，以解决特征错位问题 12。

  • 创新类型： 问题建模创新 + 方法设计创新
  • 创新性判断： 28 提出了前向影响的概念但未与推测解码结合，12 解决了 MHC 架构的推测解码问题但未考虑信息论压缩。本文首次将前向信息熵驱动的压缩与架构对齐的推测解码联合优化，解决了两个独立优化目标之间的冲突。

该论文两个创新点之间的关系：

创新点一解决“如何从信息论角度统一剪枝与缓存策略”，创新点二解决“如何在压缩基础上优化解码过程”。二者属于同一篇论文主题（训练无关推理加速），但分别对应“压缩/剪枝”和“解码/生成”两个技术层面，逻辑上形成“先压缩后解码”的递进关系，不存在重复。

论文方向二：LLM 服务系统与异构资源编排

拟定论文题目： 面向生产级 LLM 部署的动态资源编排：从异构训练模拟到运行时并行度切换与长上下文调度

论文核心问题： 如何在异构硬件、动态负载和长上下文场景下，实现 LLM 训练与推理资源的自适应编排，包括异构训练模拟、MoE 模型运行时并行度切换以及长上下文解码调度。

创新点三：异构感知的训练模拟器与运行时并行度无缝切换机制

大多数现有 AI 训练模拟器假设同质化的计算和网络基础设施，无法反映真实世界中由于多模态/MoE 架构、公有云硬件快速迭代以及地理分布式部署带来的异构性 2229。少数现有方法开始关注异构环境下的负载均衡和通信优化，但通常将张量并行（TP）和专家并行（EP）视为两种独立的部署方案，生产工作负载在突发请求和长尾拖后腿场景下跨越两者边界时，固定布局会损失性能 2922。为此，本文提出一种异构感知的统一框架：在训练模拟端，Xsim 支持非均匀工作负载划分、异构感知的集体通信（自定义环构建和分块划分）以及可复用的异构感知抽象 22；在推理服务端，Moebius 实现运行时 TP/EP 无缝切换，利用两者计算相同函数、共享字节级相同专家权重和 KV Cache 的特性，在不重启引擎或丢弃正在处理的请求的前提下完成布局切换 29。

  • 创新类型： 系统框架创新 + 在线反馈机制创新
  • 创新性判断： 22 专注于训练模拟的异构感知，29 专注于推理服务的运行时切换。本文首次将两者结合，提出从训练模拟到推理部署的端到端异构编排方案，并利用模拟器输出的性能模型指导运行时切换决策。

创新点四：页感知的长上下文解码调度与自适应效用驱动的资源编排
