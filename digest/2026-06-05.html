论文方向一：LLM 推理服务调度与资源配置优化

拟定论文题目：面向在线 LLM 推理服务的 SLO 感知滑动窗口调度与自适应注意力压缩系统

论文核心问题：如何在保证细粒度服务质量（SLO）的前提下，通过动态批处理调度与 KV 缓存压缩的协同优化，提升 LLM 在线推理服务的吞吐量并降低资源开销。

创新点一：SLO 感知的滑动窗口动态批处理调度

大多数现有方法采用贪婪式或固定大小的批处理分块策略，难以在请求延迟约束与系统吞吐之间取得平衡，导致资源利用率低下且对细粒度 QoS 差异化的支持不足 16。少数现有方法引入了基于预测的调度机制，但通常依赖粗粒度的输出约束或静态优先级队列，无法有效应对在线推理中请求到达模式与计算需求的动态变化 5。为此，本文提出一种 SLO 感知的滑动窗口调度方法，结合轻量级批处理延迟预测器与多级优先级排序器，在每次迭代中动态调整批处理分块大小，以在满足严格延迟约束的同时最大化系统吞吐量。

  • 创新类型：方法设计创新
  • 创新性判断：该创新点基于池内文献 16 的 SlidingServe 思想，但进一步融合了 5 中异步流水线调度与 11 中查询感知缓存融合的视角，将批处理调度与下游缓存压缩协同考虑，具有明确的增量贡献。

创新点二：自适应 GQA-to-MLA 过渡与可编程稀疏注意力协同压缩

大多数现有方法在推理时采用统一的注意力机制（如 GQA 或 MHA），其 KV 缓存开销随序列长度线性增长，成为高并发场景下的主要瓶颈 7。少数现有方法通过层自适应过渡（如 GQA-to-MLA）或稀疏注意力算法来压缩缓存，但通常将压缩策略与调度系统分离设计，导致压缩收益无法在调度层面被充分利用 22。为此，本文提出一种协同压缩框架，将自适应 GQA-to-MLA 过渡与可编程稀疏注意力系统集成到调度器的决策循环中，使压缩策略能够根据当前批处理的负载特征与 SLO 约束动态调整，从而在保持模型质量的同时最大化缓存压缩率。

  • 创新类型：系统框架创新 + 方法设计创新
  • 创新性判断：该创新点将 7 的层自适应过渡与 22 的可编程稀疏注意力系统进行融合，并引入调度感知的压缩决策机制，解决了现有方法中调度与压缩分离导致的效率损失问题。

论文方向二：LLM Agent 记忆与上下文管理机制

拟定论文题目：面向 LLM Agent 长对话的图结构记忆重建与零拷贝语义传播架构

论文核心问题：如何突破 LLM Agent 在长对话与多轮交互中的上下文窗口限制，通过轻量级记忆重建与高效语义传播机制，实现高保真度的历史信息恢复与低延迟推理。

创新点三：图结构记忆重建与主动检索机制

大多数现有方法采用静态的“检索-推理”流水线，将对话历史压缩后存储为平面文本或向量嵌入，在检索时无法根据推理过程中发现的中间证据动态调整访问路径，导致关键信息丢失 1018。少数现有方法引入了图结构记忆或分层检索网络，但通常依赖 LLM 驱动的显式提取与多查询搜索，推理成本高且延迟大 3。为此，本文提出一种基于 Cue-Tag-Content 关联图的记忆重建机制，将记忆表示为带有语义标签的图结构，并设计主动重建算法，使 Agent 在推理过程中能够根据已积累的证据迭代式地探索和剪枝检索路径，从而在不引发组合爆炸的前提下实现动态上下文恢复。

  • 创新类型：问题建模创新 + 方法设计创新
  • 创新性判断：该创新点融合了 18 的图记忆思想与 10 的轻量级检索设计，但通过主动重建机制解决了静态检索无法适应推理过程的问题，具有明确的创新性。

创新点四：零拷贝语义传播架构与流式注意力图更新

大多数现有方法在 Agent 间或 Agent 内部传递信息时依赖自然语言消息或显式序列化，导致高推理成本、离散化过程中的信息损失以及语义冗余 8。少数现有方法探索了潜在通信（如嵌入、隐藏状态或 KV 缓存直接传递），但通常缺乏对动态演化注意力图的高效流式更新支持 6。为此，本文提出一种零拷贝语义传播架构，在内存中直接维护一个持续演化的注意力图，通过自适应剪枝规则约束动态邻域更新的计算开销，并利用 Rust-Python 异构流水线实现亚毫秒级的事件解析与图传播，从而在保持语义完整性的同时实现极低延迟的上下文共享。

  • 创新类型：系统框架创新 + 性能优化创新
  • 创新性判断：该创新点将 6 的零拷贝流式架构与 8 的潜在通信框架相结合，并针对 Agent 对话场景设计了注意力图的动态更新与剪枝策略，解决了现有方法中语义传播延迟高与信息损失的问题。

论文方向三：LLM 后训练与推理效率的算法-系统协同优化

拟定论文题目：面向 LLM 后训练的自适应 Rollout 分配与组策略优化中的梯度几何改进方法

论文核心问题：如何从算法层面解决 LLM 后训练（RLVR）中固定 Rollout 预算导致的效率低下问题，以及组策略优化（GRPO）中梯度几何退化导致的更新失效问题，从而提升训练与推理的协同效率。

创新点五：跨 epoch 自适应 Rollout 分配优化

大多数现有方法在 LLM 后训练中为每个提示分配固定的 Rollout 预算，忽略了不同提示在训练信号上的巨大差异，导致计算资源浪费在信息量低的样本上 24。少数现有方法尝试了自适应分配策略，但通常将问题简化为单轮决策，未能考虑跨 epoch 的预算耦合与边际收益递减特性 5。为此，本文提出一种跨 epoch 自适应 Rollout 分配方法，将问题建模为在线资源分配问题，通过维护每个提示成功概率的 Beta 后验分布，并利用后验期望伯努利方差作为额外 Rollout 价值的贝叶斯估计，结合 Fenchel 对偶重写与投影在线梯度下降，在固定全局预算下实现提示间与 epoch 间的最优分配。

  • 创新类型：问题建模创新 + 优化求解创新
