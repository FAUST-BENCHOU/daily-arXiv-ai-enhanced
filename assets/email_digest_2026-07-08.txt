## 三篇论文方向与六个创新点

### 论文方向一：LLM 推理与 KV 缓存压缩

**拟定论文题目：** 面向长上下文 LLM 推理的预测性在线剪枝与跨层残差分解协同压缩方法

**论文核心问题：** 如何在无需重训的前提下，通过预测性在线剪枝、频率引导深度共享与跨层残差分解的协同设计，在长上下文 LLM 推理中实现高压缩比与任务保真度的平衡。

#### 创新点一：预测性在线剪枝与频率引导深度共享的协同压缩机制

大多数现有方法采用静态启发式或代理分数进行 KV 缓存逐出，难以追踪未来 token 的效用变化，导致压缩策略在相关性偏移时表现脆弱 [8](https://FAUST-BENCHOU.github.io/daily-arXiv-ai-enhanced/index.html?date=2026-07-08&paperId=2607.05061)[14](https://FAUST-BENCHOU.github.io/daily-arXiv-ai-enhanced/index.html?date=2026-07-08&paperId=2607.06519)[26](https://FAUST-BENCHOU.github.io/daily-arXiv-ai-enhanced/index.html?date=2026-07-08&paperId=2607.06523)。少数现有方法引入学习型逐出策略或频率引导的深度共享，但前者通常需要密集注意力图的计算开销，后者在跨层共享时对检索敏感 token 的保留不足 [8](https://FAUST-BENCHOU.github.io/daily-arXiv-ai-enhanced/index.html?date=2026-07-08&paperId=2607.05061)[14](https://FAUST-BENCHOU.github.io/daily-arXiv-ai-enhanced/index.html?date=2026-07-08&paperId=2607.06519)。为此，本文提出将预测性在线剪枝（KVpop 式未来注意力监督）与频率引导的深度共享（FreqDepthKV 式低/高频分解）进行协同集成，在剪枝阶段利用未来注意力目标训练逐出评分器，在共享阶段通过在线探针分配注意力头到共享深度或精确缓存模式，以在保持检索能力的同时实现更高压缩比。

- **创新类型：** 方法设计创新 + 约束处理创新
- **创新性判断：** 池内文献 [8](https://FAUST-BENCHOU.github.io/daily-arXiv-ai-enhanced/index.html?date=2026-07-08&paperId=2607.05061) 提出了预测性在线剪枝但未涉及跨层共享，[14](https://FAUST-BENCHOU.github.io/daily-arXiv-ai-enhanced/index.html?date=2026-07-08&paperId=2607.06519) 提出了频率引导深度共享但未与在线剪枝结合，[26](https://FAUST-BENCHOU.github.io/daily-arXiv-ai-enhanced/index.html?date=2026-07-08&paperId=2607.06523) 提出了 token 自适应跨层分解但未引入未来注意力监督。本文的协同机制填补了这三者之间的空白，属于方法层面的组合创新。

#### 创新点二：token 自适应跨层残差分解与校准自由在线误差追踪

大多数现有方法对跨层 KV 状态施加统一压缩预算，忽略了不同 token 在检索和推理中的差异化重要性，导致关键证据被过度压缩 [14](https://FAUST-BENCHOU.github.io/daily-arXiv-ai-enhanced/index.html?date=2026-07-08&paperId=2607.06519)[26](https://FAUST-BENCHOU.github.io/daily-arXiv-ai-enhanced/index.html?date=2026-07-08&paperId=2607.06523)。少数现有方法引入 token 自适应路由或在线误差追踪，但通常需要校准数据集或重训基础模型，限制了部署灵活性 [26](https://FAUST-BENCHOU.github.io/daily-arXiv-ai-enhanced/index.html?date=2026-07-08&paperId=2607.06523)。为此，本文提出一种校准自由的在线误差追踪机制，利用注意力输出探针实时监测压缩引入的误差，并动态调整 token 特定的残差秩分配，在不依赖预校准数据的前提下实现 token 级别的自适应压缩。

- **创新类型：** 问题建模创新 + 方法设计创新
- **创新性判断：** 池内文献 [26](https://FAUST-BENCHOU.github.io/daily-arXiv-ai-enhanced/index.html?date=2026-07-08&paperId=2607.06523) 提出了 token 自适应跨层分解但依赖校准，[14](https://FAUST-BENCHOU.github.io/daily-arXiv-ai-enhanced/index.html?date=2026-07-08&paperId=2607.06519) 的频率引导方法未实现 token 级别自适应。本文的校准自由在线追踪机制在部署灵活性上优于两者，属于方法层面的增量创新。

### 论文方向二：LLM 智能体可靠性与运行时诊断

**拟定论文题目：** 面向多步 LLM 智能体的早期失败预测与关键转换图引导的运行时诊断修复方法

**论文核心问题：** 如何在多步 LLM 智能体任务中，通过早期内部表征探测预测失败、定位关键错误转换，并生成可执行的修复指导，提升智能体系统的可靠性与可观测性。

#### 创新点三：基于内部表征的早期失败预测与召回控制级联中止

大多数现有方法依赖智能体的可观察行为（如中间输出、工具调用结果）来判断任务是否失败，但此时失败往往已不可逆转，且消耗了大量推理计算 [13](https://FAUST-BENCHOU.github.io/daily-arXiv-ai-enhanced/index.html?date=2026-07-08&paperId=2607.06503)[18](https://FAUST-BENCHOU.github.io/daily-arXiv-ai-enhanced/index.html?date=2026-07-08&paperId=2607.06273)。少数现有方法尝试从内部隐藏激活中预测失败，但缺乏对成功 episode 的召回率保证，导致过早中止的风险不可控 [13](https://FAUST-BENCHOU.github.io/daily-arXiv-ai-enhanced/index.html?date=2026-07-08&paperId=2607.06503)。为此，本文提出一种基于每轮内部探针的早期失败预测级联，通过分布自由校准门控和联合搜索每轮召回预算，确保成功 episode 以用户指定的全局召回率通过所有门控，从而在节省推理计算的同时避免误中止。

- **创新类型：** 问题建模创新 + 方法设计创新
- **创新性判断：** 池内文献 [13](https://FAUST-BENCHOU.github.io/daily-arXiv-ai-enhanced/index.html?date=2026-07-08&paperId=2607.06503) 提出了基于内部探针的早期中止但未提供全局召回率保证，[18](https://FAUST-BENCHOU.github.io/daily-arXiv-ai-enhanced/index.html?date=2026-07-08&paperId=2607.06273) 提出了运行时诊断但未涉及早期预测。本文的召回控制级联机制在保证成功 episode 存活率方面具有明确优势，属于方法层面的增量创新。

#### 创新点四：关键转换图引导的失败定位与行为范围修复指导

大多数现有方法在智能体失败后仅提供“成功/失败”二元反馈或盲重试，缺乏对失败原因的结构化定位和可执行的修复指导 [18](https://FAUST-BENCHOU.github.io/daily-arXiv-ai-enhanced/index.html?date=2026-07-08&paperId=2607.06273)[17](https://FAUST-BENCHOU.github.io/daily-arXiv-ai-enhanced/index.html?date=2026-07-08&paperId=2607.06065)。少数现有方法引入依赖感知的关键转换图来定位失败子轨迹，但生成的修复指导缺乏行为范围约束，容易导致过度修正或修复无效 [18](https://FAUST-BENCHOU.github.io/daily-arXiv-ai-enhanced/index.html?date=2026-07-08&paperId=2607.06273)。为此，本文提出一种结合离线正常行为模型与运行局部图检测器的失败定位方法，将定位到的失败原因转换为行为范围约束的修复指导，并通过跨迭代验证确保修复的有效性。

- **创新类型：** 方法设计创新 + 约束处理创新
- **创新性判断：** 池内文献 [18](https://FAUST-BENCHOU.github.io/daily-arXiv-ai-enhanced/index.html?date=2026-07-08&paperId=2607.06273) 提出了关键转换图定位但未约束修复行为范围，[17](https://FAUST-BENCHOU.github.io/daily-arXiv-ai-enhanced/index.html?date=2026-07-08&paperId=2607.06065) 提出了智能体代码审查但未涉及运行时诊断。本文的行为范围约束修复指导在定位与修复之间建立了更精确的映射，属于方法层面的增量创新。

### 论文方向三：LLM 系统效率与记忆架构

**拟定论文题目：** 面向 LLM 智能体的低开销进程内记忆系统与异步规划运行时协同优化方法

**论文核心问题：** 如何通过进程内记忆系统消除检索延迟瓶颈，并结合异步规划运行时与离线强化学习执行控制，在吞吐、延迟与任务质量之间取得更优权衡。

#### 创新点五：基于进程内记忆系统的低开销扩展工作记忆架构

大多数现有方法将智能体的记忆存储在网络化数据库中，每次检索需要数十到数百毫秒，导致每步检索延迟膨胀高达 83 倍 [16](https://FAUST-BENCHOU.github.io/daily-arXiv-ai-enhanced/index.html?date=2026-07-08&paperId=2607.05690)[22](https://FAUST-BENCHOU.github.io/daily-arXiv-ai-enhanced/index.html?date=2026-07-08&paperId=2607.05708)。少数现有方法通过服务层调度或“记忆优先”设计来管理延迟，但本质上仍将记忆视为外部工具而非智能体认知的一部分 [16](https://FAUST-BENCHOU.github.io/daily-arXiv-ai-enhanced/index.html?date=2026-07-08&paperId=2607.05690)。为此，本文提出一种基于进程内存储的记忆系统，利用 ~100μs 的查询延迟将记忆从外部工具转变为智能体的扩展工作记忆，并通过硬件-软件协同设计将可能共同检索的块进行共置，减少检索碎片化和 I/O 开销。

- **创新类型：** 问题建模创新 + 方法设计创新
- **创新性判断：** 池内文献 [16](https://FAUST-BENCHOU.github.io/daily-arXiv-ai-enhanced/index.html?date=2026-07-08&paperId=2607.05690) 提出了进程内记忆的理论论证但未给出完整系统实现，[22](https://FAUST-BENCHOU.github.io/daily-arXiv-ai-enhanced/index.html?date=2026-07-08&paperId=2607.05708) 提出了 MemAttention 但未完全消除网络延迟。本文的进程内记忆系统结合硬件-软件协同共置策略，在延迟消除和检索效率上具有明确优势，属于方法层面的增量创新。

#### 创新点六：异步规划运行时与离线强化学习执行控制的协同优化

大多数现有方法将 LLM 规划置于执行的关键路径上，导致推理延迟直接阻塞物理动作，难以满足实时控制需求 [23](https://FAUST-BENCHOU.github.io/daily-arXiv-ai-enhanced/index.html?date=2026-07-08&paperId=2607.05482)[11](https://FAUST-BENCHOU.github.io/daily-arXiv-ai-enhanced/index.html?date=2026-07-08&paperId=2607.05458)。少数现有方法引入异步规划或离线强化学习控制，但前者缺乏对执行过程的优先级管理，后者未与规划-执行重叠机制结合 [23](https://FAUST-BENCHOU.github.io/daily-arXiv-ai-enhanced/index.html?date=2026-07-08&paperId=2607.05482)[11](https://FAUST-BENCHOU.github.io/daily-arXiv-ai-enhanced/index.html?date=2026-07-08&paperId=2607.05458)。为此，本文提出一种将异步规划循环（多时间尺度、与执行重叠）与离线强化学习执行控制器（基于优势加权回归训练）协同集成的运行时架构，通过推测性技能流式传输隐藏 LLM 延迟，并利用 Harness MDP 形式化控制器的执行动作选择。

- **创新类型：** 方法设计创新 + 系统框架创新
- **创新性判断：** 池内文献 [23](https://FAUST-BENCHOU.github.io/daily-arXiv-ai-enhanced/index.html?date=2026-07-08&paperId=2607.05482) 提出了异步规划运行时但未引入学习型执行控制，[11](https://FAUST-BENCHOU.github.io/daily-arXiv-ai-enhanced/index.html?date=2026-07-08&paperId=2607.05458) 提出了离线强化学习执行控制但未与异步规划结合。本文的协同集成在系统架构层面具有创新性，属于系统框架层面的组合创新。
