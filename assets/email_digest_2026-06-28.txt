## 一、三篇论文方向与六个创新点

### 论文方向一：面向长上下文与扩散模型的推理加速与缓存管理

**拟定论文题目：** 面向长上下文与扩散模型的推理加速：基于阶段感知的缓存淘汰与动态预算分配方法

**论文核心问题：** 如何在不牺牲生成质量的前提下，通过缓存淘汰策略和动态预算分配，显著降低长上下文 LLM 和扩散 LLM 的推理延迟与显存开销。

#### 创新点一：基于内部表征变化的无注意力矩阵 KV 缓存淘汰方法

大多数现有方法基于注意力权重对 KV 缓存中的 Token 进行排序和淘汰，但注意力权重在长推理链中是一个有噪声的重要性代理，且强制模型物化注意力矩阵，阻碍了融合内核在生产推理中的使用 [3](https://FAUST-BENCHOU.github.io/daily-arXiv-ai-enhanced/index.html?date=2026-06-28&paperId=2606.27161)[5](https://FAUST-BENCHOU.github.io/daily-arXiv-ai-enhanced/index.html?date=2026-06-28&paperId=2606.26472)[15](https://FAUST-BENCHOU.github.io/daily-arXiv-ai-enhanced/index.html?date=2026-06-28&paperId=2606.26666)。少数现有方法尝试通过其他启发式规则（如频率、时效性）进行缓存淘汰，但缺乏对模型内部表征变化的直接建模，且难以与 FlashAttention 等高效推理栈无缝集成 [10](https://FAUST-BENCHOU.github.io/daily-arXiv-ai-enhanced/index.html?date=2026-06-28&paperId=2606.26105)[24](https://FAUST-BENCHOU.github.io/daily-arXiv-ai-enhanced/index.html?date=2026-06-28&paperId=2606.26120)。为此，本文提出基于“顿悟分数”（epiphany score）的缓存淘汰方法，直接从前向传播中读取模型内部表征的变化，无需注意力矩阵和额外状态，可直接在 FlashAttention 推理栈中运行，实现 16 倍于注意力评分方法的可行上下文长度 [5](https://FAUST-BENCHOU.github.io/daily-arXiv-ai-enhanced/index.html?date=2026-06-28&paperId=2606.26472)。

- **创新类型：** 方法设计创新
- **创新性判断：** 现有方法（如 H2O、ThinKV）依赖注意力权重，而本文方法通过直接度量模型内部状态变化来替代注意力权重，避免了注意力矩阵的物化开销，且与现有高效推理栈兼容，具有显著差异。

#### 创新点二：面向扩散 LLM 的层感知动态缓存预算分配与自适应并行解码方法

大多数现有方法在加速扩散 LLM 推理时采用静态缓存策略或固定的并行解码方案，未能考虑 Token 属性在不同层和解码步骤中的动态变化，导致计算复杂度随序列长度呈立方增长 [23](https://FAUST-BENCHOU.github.io/daily-arXiv-ai-enhanced/index.html?date=2026-06-28&paperId=2606.26493)[24](https://FAUST-BENCHOU.github.io/daily-arXiv-ai-enhanced/index.html?date=2026-06-28&paperId=2606.26120)。少数现有方法引入了动态缓存更新或自适应解码，但通常将缓存预算均匀分配给所有层，忽略了不同层对 Token 动态性的敏感度差异，且解码阈值固定，难以在生成质量和效率之间取得平衡 [12](https://FAUST-BENCHOU.github.io/daily-arXiv-ai-enhanced/index.html?date=2026-06-28&paperId=2606.26769)[22](https://FAUST-BENCHOU.github.io/daily-arXiv-ai-enhanced/index.html?date=2026-06-28&paperId=2606.26861)。为此，本文提出 Dynamic-dLLM 框架，包含动态缓存更新（DCU）组件，根据层间 Token 动态性自适应分配缓存更新预算；以及自适应并行解码（APD）组件，动态校准解码阈值以平衡生成质量和效率，实现无需重新训练即可显著加速扩散 LLM 推理 [24](https://FAUST-BENCHOU.github.io/daily-arXiv-ai-enhanced/index.html?date=2026-06-28&paperId=2606.26120)。

- **创新类型：** 方法设计创新 + 约束处理创新
- **创新性判断：** 现有方法（如静态缓存、固定并行解码）忽略了层间差异和 Token 动态性，本文通过层感知的预算分配和动态阈值校准，在无需重新训练的前提下实现了更优的效率-质量权衡。

**该论文两个创新点之间的关系：**
创新点一解决“如何在不依赖注意力矩阵的情况下高效淘汰 KV 缓存”，创新点二解决“如何为扩散 LLM 动态分配缓存预算和解码策略”。二者属于同一篇论文主题（推理加速与缓存管理），但分别对应自回归 LLM 的缓存淘汰和扩散 LLM 的缓存预算分配，技术层面不同，不存在重复。

**建议实验设计：**

### 论文方向二：面向 AI 智能体与代码系统的结构化可靠性与验证

**拟定论文题目：** 面向 AI 智能体与代码系统的结构化可靠性：确定性锚定与规范-代码漂移检测方法

**论文核心问题：** 如何通过轻量级静态分析和形式化验证，提高 AI 代码智能体的导航可复现性、修复可靠性以及规范-代码一致性。

#### 创新点三：基于轻量级静态分析的确定性锚定方法

大多数现有方法依赖 LLM 通过关键词搜索在代码仓库中导航，但忽略了调用图、继承层次和配置依赖等结构关系，导致导航行为随机且难以跨运行复现 [1](https://FAUST-BENCHOU.github.io/daily-arXiv-ai-enhanced/index.html?date=2026-06-28&paperId=2606.26979)[16](https://FAUST-BENCHOU.github.io/daily-arXiv-ai-enhanced/index.html?date=2026-06-28&paperId=2606.26978)[19](https://FAUST-BENCHOU.github.io/daily-arXiv-ai-enhanced/index.html?date=2026-06-28&paperId=2606.26590)。少数现有方法尝试引入静态分析或结构化提示，但通常需要完整的程序分析或昂贵的重训练，且未能系统量化不同粒度结构注释对导航稳定性的影响 [14](https://FAUST-BENCHOU.github.io/daily-arXiv-ai-enhanced/index.html?date=2026-06-28&paperId=2606.27045)[30](https://FAUST-BENCHOU.github.io/daily-arXiv-ai-enhanced/index.html?date=2026-06-28&paperId=2606.27154)。为此，本文提出确定性锚定方法，通过将轻量级静态分析结果（如调用/继承拓扑）以纯文本注释形式注入智能体上下文，约束概率性探索，使导航更加规范化和可复现，实验表明该方法在定位准确性和运行间稳定性上均有显著提升 [1](https://FAUST-BENCHOU.github.io/daily-arXiv-ai-enhanced/index.html?date=2026-06-28&paperId=2606.26979)。

- **创新类型：** 问题建模创新 + 方法设计创新
- **创新性判断：** 现有方法（如 Codex）依赖纯关键词搜索，导航具有随机性；本文通过注入轻量级静态结构信息作为“锚点”，在不改变模型架构的前提下提高了导航的确定性和可复现性。

#### 创新点四：基于规范-代码耦合与漂移门控的持续一致性验证方法

大多数现有方法在 AI 辅助软件开发中，代码快速演化而规范未能同步更新，导致规范-代码漂移，且这种分歧在修复成本高昂之前往往不可见 [14](https://FAUST-BENCHOU.github.io/daily-arXiv-ai-enhanced/index.html?date=2026-06-28&paperId=2606.27045)[19](https://FAUST-BENCHOU.github.io/daily-arXiv-ai-enhanced/index.html?date=2026-06-28&paperId=2606.26590)[20](https://FAUST-BENCHOU.github.io/daily-arXiv-ai-enhanced/index.html?date=2026-06-28&paperId=2606.26300)。少数现有方法引入了规范驱动的开发或形式化验证，但通常需要手工编码符号执行或完整的规范重写，难以扩展到真实策略规范的广度 [4](https://FAUST-BENCHOU.github.io/daily-arXiv-ai-enhanced/index.html?date=2026-06-28&paperId=2606.26649)[28](https://FAUST-BENCHOU.github.io/daily-arXiv-ai-enhanced/index.html?date=2026-06-28&paperId=2605.00410)。为此，本文提出规范-代码耦合与漂移门控框架，通过机器可读的规范图、垂直切片增长协议和漂移门控机制，将规范-代码分歧作为阻塞性合并条件，确保代码演化始终与规范保持同步，实验表明该方法能有效检测并阻止隐蔽的修复失败 [14](https://FAUST-BENCHOU.github.io/daily-arXiv-ai-enhanced/index.html?date=2026-06-28&paperId=2606.27045)。

- **创新类型：** 系统框架创新 + 在线反馈机制创新
- **创新性判断：** 现有方法（如 Checkov 移除）仅检查静态分析告警是否消失，忽略了规划有效性和行为变化；本文通过将规范-代码一致性作为阻塞性合并条件，实现了持续验证。

### 论文方向三：面向异构集群与分布式训练的资源调度与加速

**拟定论文题目：** 面向异构集群的分布式训练：基于增益感知的特征筛选与张量重分片仿真方法

**论文核心问题：** 如何在异构计算和网络基础设施下，通过特征筛选和张量重分片仿真，提高分布式训练的计算效率和资源利用率。

#### 创新点五：基于指数移动平均增益感知的特征筛选方法

大多数现有方法在 GBDT 训练中采用随机特征子采样（feature_fraction），丢弃特征时不考虑其预测效用，导致大量计算资源浪费在低增益特征上 [7](https://FAUST-BENCHOU.github.io/daily-arXiv-ai-enhanced/index.html?date=2026-06-28&paperId=2606.26337)[26](https://FAUST-BENCHOU.github.io/daily-arXiv-ai-enhanced/index.html?date=2026-06-28&paperId=2606.26822)。少数现有方法尝试基于特征重要性进行筛选，但通常需要完整的训练过程或额外的验证步骤，且无法适应训练过程中特征重要性的动态变化 [2](https://FAUST-BENCHOU.github.io/daily-arXiv-ai-enhanced/index.html?date=2026-06-28&paperId=2606.26657)[17](https://FAUST-BENCHOU.github.io/daily-arXiv-ai-enhanced/index.html?date=2026-06-28&paperId=2606.26633)。为此，本文提出 EMA-FS 方法，在提升迭代中维护每个特征分裂增益的指数移动平均，经过短时间预热后，仅对历史增益排名前 K 的特征构建直方图，实现信息驱动的特征筛选，与 LightGBM 的直方图减法技巧完全兼容，无需修改核心例程 [7](https://FAUST-BENCHOU.github.io/daily-arXiv-ai-enhanced/index.html?date=2026-06-28&paperId=2606.26337)。

- **创新类型：** 方法设计创新 + 性能预测创新
- **创新性判断：** 现有方法（如随机子采样）丢弃特征时不考虑预测效用；本文通过 EMA 维护特征增益的动态排名，实现了信息驱动的筛选，且与现有框架兼容。

#### 创新点六：面向异构 AI 系统的统一张量重分片仿真方法

大多数现有 AI 训练模拟器假设同质计算和网络基础设施，无法准确建模真实世界中由于多模态架构、公共云硬件异构性和地理分布式部署带来的异构性 [6](https://FAUST-BENCHOU.github.io/daily-arXiv-ai-enhanced/index.html?date=2026-06-28&paperId=2606.26997)[17](https://FAUST-BENCHOU.github.io/daily-arXiv-ai-enhanced/index.html?date=2026-06-28&paperId=2606.26633)[29](https://FAUST-BENCHOU.github.io/daily-arXiv-ai-enhanced/index.html?date=2026-06-28&paperId=2606.27005)。少数现有方法开始关注异构训练，但通常缺乏对统一张量重分片技术的支持，且无法灵活指定包含自定义设备组和网络拓扑的部署方案 [13](https://FAUST-BENCHOU.github.io/daily-arXiv-ai-enhanced/index.html?date=2026-06-28&paperId=2606.26308)[26](https://FAUST-BENCHOU.github.io/daily-arXiv-ai-enhanced/index.html?date=2026-06-28&paperId=2606.26822)。为此，本文提出 Xsim 模拟器，支持通过非均匀工作负载分区实现负载均衡、通过定制环构建和块分区实现异构感知的集合通信、以及可复用的异构感知抽象，用于新兴的流水线并行算法和非均匀张量重分片技术 [17](https://FAUST-BENCHOU.github.io/daily-arXiv-ai-enhanced/index.html?date=2026-06-28&paperId=2606.26633)。

- **创新类型：** 系统框架创新 + 特征表示创新
- **创新性判断：** 现有模拟器（如 ASTRA-sim）假设同质基础设施；本文通过支持非均匀分区、异构感知通信和灵活部署抽象，填补了异构 AI 训练仿真的空白。
