## 论文方向一：LLM 推理服务调度与资源配置优化

**拟定论文题目**：面向在线 LLM 推理服务的 SLO 感知滑动窗口调度与自适应注意力压缩系统

**论文核心问题**：如何在保证细粒度服务质量（SLO）的前提下，通过动态批处理调度与 KV 缓存压缩的协同优化，提升 LLM 在线推理服务的吞吐量并降低资源开销。

### 创新点一：SLO 感知的滑动窗口动态批处理调度

大多数现有方法采用贪婪式或固定大小的批处理分块策略，难以在请求延迟约束与系统吞吐之间取得平衡，导致资源利用率低下且对细粒度 QoS 差异化的支持不足 [16](https://FAUST-BENCHOU.github.io/daily-arXiv-ai-enhanced/index.html?date=2026-06-05&paperId=2606.05933)。少数现有方法引入了基于预测的调度机制，但通常依赖粗粒度的输出约束或静态优先级队列，无法有效应对在线推理中请求到达模式与计算需求的动态变化 [5](https://FAUST-BENCHOU.github.io/daily-arXiv-ai-enhanced/index.html?date=2026-06-05&paperId=2606.05597)。为此，本文提出一种 SLO 感知的滑动窗口调度方法，结合轻量级批处理延迟预测器与多级优先级排序器，在每次迭代中动态调整批处理分块大小，以在满足严格延迟约束的同时最大化系统吞吐量。

- **创新类型**：方法设计创新
- **创新性判断**：该创新点基于池内文献 [16](https://FAUST-BENCHOU.github.io/daily-arXiv-ai-enhanced/index.html?date=2026-06-05&paperId=2606.05933) 的 SlidingServe 思想，但进一步融合了 [5](https://FAUST-BENCHOU.github.io/daily-arXiv-ai-enhanced/index.html?date=2026-06-05&paperId=2606.05597) 中异步流水线调度与 [11](https://FAUST-BENCHOU.github.io/daily-arXiv-ai-enhanced/index.html?date=2026-06-05&paperId=2606.05875) 中查询感知缓存融合的视角，将批处理调度与下游缓存压缩协同考虑，具有明确的增量贡献。

### 创新点二：自适应 GQA-to-MLA 过渡与可编程稀疏注意力协同压缩

大多数现有方法在推理时采用统一的注意力机制（如 GQA 或 MHA），其 KV 缓存开销随序列长度线性增长，成为高并发场景下的主要瓶颈 [7](https://FAUST-BENCHOU.github.io/daily-arXiv-ai-enhanced/index.html?date=2026-06-05&paperId=2606.05868)。少数现有方法通过层自适应过渡（如 GQA-to-MLA）或稀疏注意力算法来压缩缓存，但通常将压缩策略与调度系统分离设计，导致压缩收益无法在调度层面被充分利用 [22](https://FAUST-BENCHOU.github.io/daily-arXiv-ai-enhanced/index.html?date=2026-06-05&paperId=2606.06453)。为此，本文提出一种协同压缩框架，将自适应 GQA-to-MLA 过渡与可编程稀疏注意力系统集成到调度器的决策循环中，使压缩策略能够根据当前批处理的负载特征与 SLO 约束动态调整，从而在保持模型质量的同时最大化缓存压缩率。

- **创新类型**：系统框架创新 + 方法设计创新
- **创新性判断**：该创新点将 [7](https://FAUST-BENCHOU.github.io/daily-arXiv-ai-enhanced/index.html?date=2026-06-05&paperId=2606.05868) 的层自适应过渡与 [22](https://FAUST-BENCHOU.github.io/daily-arXiv-ai-enhanced/index.html?date=2026-06-05&paperId=2606.06453) 的可编程稀疏注意力系统进行融合，并引入调度感知的压缩决策机制，解决了现有方法中调度与压缩分离导致的效率损失问题。

创新点一解决“如何动态调度批处理以保障 SLO”，创新点二解决“如何在调度决策中协同压缩 KV 缓存以降低资源开销”。二者属于同一论文主题（LLM 推理服务优化），但分别对应调度策略设计与缓存压缩机制设计，逻辑上形成递进：调度器感知压缩状态后，可做出更优的批处理决策。

## 论文方向二：LLM Agent 记忆与上下文管理机制

**拟定论文题目**：面向 LLM Agent 长对话的图结构记忆重建与零拷贝语义传播架构

**论文核心问题**：如何突破 LLM Agent 在长对话与多轮交互中的上下文窗口限制，通过轻量级记忆重建与高效语义传播机制，实现高保真度的历史信息恢复与低延迟推理。

### 创新点三：图结构记忆重建与主动检索机制

大多数现有方法采用静态的“检索-推理”流水线，将对话历史压缩后存储为平面文本或向量嵌入，在检索时无法根据推理过程中发现的中间证据动态调整访问路径，导致关键信息丢失 [10](https://FAUST-BENCHOU.github.io/daily-arXiv-ai-enhanced/index.html?date=2026-06-05&paperId=2606.05182)[18](https://FAUST-BENCHOU.github.io/daily-arXiv-ai-enhanced/index.html?date=2026-06-05&paperId=2606.06036)。少数现有方法引入了图结构记忆或分层检索网络，但通常依赖 LLM 驱动的显式提取与多查询搜索，推理成本高且延迟大 [3](https://FAUST-BENCHOU.github.io/daily-arXiv-ai-enhanced/index.html?date=2026-06-05&paperId=2606.06473)。为此，本文提出一种基于 Cue-Tag-Content 关联图的记忆重建机制，将记忆表示为带有语义标签的图结构，并设计主动重建算法，使 Agent 在推理过程中能够根据已积累的证据迭代式地探索和剪枝检索路径，从而在不引发组合爆炸的前提下实现动态上下文恢复。

- **创新类型**：问题建模创新 + 方法设计创新
- **创新性判断**：该创新点融合了 [18](https://FAUST-BENCHOU.github.io/daily-arXiv-ai-enhanced/index.html?date=2026-06-05&paperId=2606.06036) 的图记忆思想与 [10](https://FAUST-BENCHOU.github.io/daily-arXiv-ai-enhanced/index.html?date=2026-06-05&paperId=2606.05182) 的轻量级检索设计，但通过主动重建机制解决了静态检索无法适应推理过程的问题，具有明确的创新性。

### 创新点四：零拷贝语义传播架构与流式注意力图更新

大多数现有方法在 Agent 间或 Agent 内部传递信息时依赖自然语言消息或显式序列化，导致高推理成本、离散化过程中的信息损失以及语义冗余 [8](https://FAUST-BENCHOU.github.io/daily-arXiv-ai-enhanced/index.html?date=2026-06-05&paperId=2606.05711)。少数现有方法探索了潜在通信（如嵌入、隐藏状态或 KV 缓存直接传递），但通常缺乏对动态演化注意力图的高效流式更新支持 [6](https://FAUST-BENCHOU.github.io/daily-arXiv-ai-enhanced/index.html?date=2026-06-05&paperId=2606.05733)。为此，本文提出一种零拷贝语义传播架构，在内存中直接维护一个持续演化的注意力图，通过自适应剪枝规则约束动态邻域更新的计算开销，并利用 Rust-Python 异构流水线实现亚毫秒级的事件解析与图传播，从而在保持语义完整性的同时实现极低延迟的上下文共享。

- **创新类型**：系统框架创新 + 性能优化创新
- **创新性判断**：该创新点将 [6](https://FAUST-BENCHOU.github.io/daily-arXiv-ai-enhanced/index.html?date=2026-06-05&paperId=2606.05733) 的零拷贝流式架构与 [8](https://FAUST-BENCHOU.github.io/daily-arXiv-ai-enhanced/index.html?date=2026-06-05&paperId=2606.05711) 的潜在通信框架相结合，并针对 Agent 对话场景设计了注意力图的动态更新与剪枝策略，解决了现有方法中语义传播延迟高与信息损失的问题。

## 论文方向三：LLM 后训练与推理效率的算法-系统协同优化

**拟定论文题目**：面向 LLM 后训练的自适应 Rollout 分配与组策略优化中的梯度几何改进方法

**论文核心问题**：如何从算法层面解决 LLM 后训练（RLVR）中固定 Rollout 预算导致的效率低下问题，以及组策略优化（GRPO）中梯度几何退化导致的更新失效问题，从而提升训练与推理的协同效率。

### 创新点五：跨 epoch 自适应 Rollout 分配优化

大多数现有方法在 LLM 后训练中为每个提示分配固定的 Rollout 预算，忽略了不同提示在训练信号上的巨大差异，导致计算资源浪费在信息量低的样本上 [24](https://FAUST-BENCHOU.github.io/daily-arXiv-ai-enhanced/index.html?date=2026-06-05&paperId=2606.05606)。少数现有方法尝试了自适应分配策略，但通常将问题简化为单轮决策，未能考虑跨 epoch 的预算耦合与边际收益递减特性 [5](https://FAUST-BENCHOU.github.io/daily-arXiv-ai-enhanced/index.html?date=2026-06-05&paperId=2606.05597)。为此，本文提出一种跨 epoch 自适应 Rollout 分配方法，将问题建模为在线资源分配问题，通过维护每个提示成功概率的 Beta 后验分布，并利用后验期望伯努利方差作为额外 Rollout 价值的贝叶斯估计，结合 Fenchel 对偶重写与投影在线梯度下降，在固定全局预算下实现提示间与 epoch 间的最优分配。

- **创新类型**：问题建模创新 + 优化求解创新
- **创新性判断**：该创新点直接基于 [24](https://FAUST-BENCHOU.github.io/daily-arXiv-ai-enhanced/index.html?date=2026-06-05&paperId=2606.05606) 的 CERO 方法，但进一步将其与 [5](https://FAUST-BENCHOU.github.io/daily-arXiv-ai-enhanced/index.html?date=2026-06-05&paperId=2606.05597) 中异步流水线的视角结合，并引入 [27](https://FAUST-BENCHOU.github.io/daily-arXiv-ai-enhanced/index.html?date=2026-06-05&paperId=2606.05800) 中梯度几何分析的思想，使自适应分配能够感知梯度质量，具有明确的增量贡献。
- **文献支撑**：

### 创新点六：组策略优化中的梯度几何改进与有效更新恢复

大多数现有方法采用 GRPO 风格的组相对更新，通过采样多个 Rollout 构建归一化学习信号，但增加 Rollout 数量并不能可靠地增强学习效果 [27](https://FAUST-BENCHOU.github.io/daily-arXiv-ai-enhanced/index.html?date=2026-06-05&paperId=2606.05800)。少数现有方法分析了梯度几何退化问题，发现组归一化会导致每个 Rollout 的策略梯度特征集中到低秩、有符号的几何结构中，在聚合时产生大量抵消，削弱有效更新 [5](https://FAUST-BENCHOU.github.io/daily-arXiv-ai-enhanced/index.html?date=2026-06-05&paperId=2606.05597)。为此，本文提出一种子空间自适应几何插件（SALT），通过估计小批量 Gram 几何中的主导共享子空间，将组相对系数分解为共享通道与残差通道，并在有符号抵消严重时自适应放大残差通道，从而在不修改 GRPO 核心框架的前提下恢复有效更新几何。

- **创新类型**：方法设计创新 + 约束处理创新
- **创新性判断**：该创新点直接基于 [27](https://FAUST-BENCHOU.github.io/daily-arXiv-ai-enhanced/index.html?date=2026-06-05&paperId=2606.05800) 的 SALT 方法，但将其与 [24](https://FAUST-BENCHOU.github.io/daily-arXiv-ai-enhanced/index.html?date=2026-06-05&paperId=2606.05606) 的自适应 Rollout 分配相结合，使梯度几何改进能够感知 Rollout 预算的动态变化，解决了现有方法中梯度改进与预算分配分离的问题。

**该论文两个创新点之间的关系**：
创新点五解决“如何自适应分配 Rollout 预算以提升训练效率”，创新点六解决“如何在组策略优化中恢复有效梯度更新”。二者属于同一论文主题（LLM 后训练效率优化），但分别对应预算分配策略与梯度几何改进，逻辑上形成递进：自适应分配确保计算资源投向高价值样本，梯度几何改进确保这些样本产生的更新信号不被抵消。
