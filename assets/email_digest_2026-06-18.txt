## 三篇论文方向与六个创新点

### 论文方向一：面向动态推理负载的 LLM 服务拓扑与资源配置在线调优

**拟定论文题目：** 面向动态推理负载的大语言模型服务拓扑与资源配置在线闭环调优方法

**论文核心问题：** 如何在 LLM 在线推理服务中，根据实时变化的负载特征，动态调整模型并行拓扑（TP/PP 配置）和 GPU 资源配置，以在保证服务质量的前提下降低推理成本。

#### 创新点一：负载感知的并行拓扑动态重配置方法

大多数现有方法将 LLM 推理系统的模型并行拓扑（TP/PP 配置）视为静态设定，无法在运行时根据负载变化进行调整，导致在负载波动场景下资源利用率低下或服务质量下降 [1](https://FAUST-BENCHOU.github.io/daily-arXiv-ai-enhanced/index.html?date=2026-06-18&paperId=2606.18967)[9](https://FAUST-BENCHOU.github.io/daily-arXiv-ai-enhanced/index.html?date=2026-06-18&paperId=2606.18741)[12](https://FAUST-BENCHOU.github.io/daily-arXiv-ai-enhanced/index.html?date=2026-06-18&paperId=2606.18600)。少数现有方法开始探索运行时重配置，但通常需要重启服务或中断推理过程，导致分钟级的服务中断和 KV 缓存丢失，难以满足在线服务的连续性要求 [9](https://FAUST-BENCHOU.github.io/daily-arXiv-ai-enhanced/index.html?date=2026-06-18&paperId=2606.18741)。为此，本文提出负载感知的并行拓扑动态重配置方法，通过解耦模型并行拓扑与运行时状态，设计二维 KV 缓存迁移机制以保留可复用缓存状态，实现低停机时间的在线拓扑切换。

- **创新类型：** 方法设计创新 + 系统机制创新
- **创新性判断：** 现有工作 [9](https://FAUST-BENCHOU.github.io/daily-arXiv-ai-enhanced/index.html?date=2026-06-18&paperId=2606.18741) 已提出低停机时间重配置框架，但尚未与负载预测和在线反馈机制深度耦合。本文创新点在于将拓扑重配置决策与实时负载特征绑定，并引入缓存状态迁移以消除重配置后的冷启动开销。

#### 创新点二：异构 GPU 集群中成本感知的资源配置优化

大多数现有方法在 LLM 推理部署中依赖同构 GPU 集群，或简单地将异构 GPU 视为独立资源池进行负载均衡，未能充分利用不同 GPU 类型的互补可用性模式和成本差异 [12](https://FAUST-BENCHOU.github.io/daily-arXiv-ai-enhanced/index.html?date=2026-06-18&paperId=2606.18600)。少数现有方法开始探索异构 spot 实例集群，但通常采用基于 roofline 模型的静态性能估计器，难以适应在线推理中请求长度分布和并发度的实时变化 [12](https://FAUST-BENCHOU.github.io/daily-arXiv-ai-enhanced/index.html?date=2026-06-18&paperId=2606.18600)。为此，本文提出基于动态规划的成本感知资源配置优化方法，将 GPU 类型选择、实例数量分配和请求路由联合建模为约束优化问题，并引入在线性能反馈以持续校正资源配置决策。

- **创新类型：** 问题建模创新 + 优化求解创新
- **创新性判断：** 现有工作 [12](https://FAUST-BENCHOU.github.io/daily-arXiv-ai-enhanced/index.html?date=2026-06-18&paperId=2606.18600) 已提出针对异构 spot 集群的静态优化方案，但未考虑负载动态变化对性能估计的影响。本文创新点在于将资源配置优化与在线性能反馈闭环耦合，实现成本与性能的实时权衡。

### 论文方向二：面向 LLM 训练的数据效率与模型结构协同优化

**拟定论文题目：** 面向大语言模型训练的数据选择与模型结构协同优化方法

**论文核心问题：** 如何在 LLM 训练过程中，通过数据选择策略与模型结构压缩的协同设计，在降低训练和推理成本的同时保持模型性能。

#### 创新点三：自适应数据选择与模型状态协同优化方法

大多数现有 LLM 数据选择方法采用静态启发式过滤或基于固定参考模型的 excess-loss 方法，无法适应训练过程中代理模型（proxy model）的持续演化，导致早期选择的高质量数据在后期变得冗余 [26](https://FAUST-BENCHOU.github.io/daily-arXiv-ai-enhanced/index.html?date=2026-06-18&paperId=2606.18650)。少数现有方法引入基于影响函数（influence function）的双层优化框架，但需要计算不可行的逆 Hessian 矩阵，限制了在大规模场景下的实用性 [26](https://FAUST-BENCHOU.github.io/daily-arXiv-ai-enhanced/index.html?date=2026-06-18&paperId=2606.18650)。为此，本文提出自适应数据选择与模型状态协同优化方法，通过将双层优化重新表述为带惩罚的单层目标，利用拉格朗日乘子避免逆 Hessian 计算，并引入动态参考模型更新机制以保持数据选择与模型状态的持续对齐。

- **创新类型：** 问题建模创新 + 方法设计创新
- **创新性判断：** 现有工作 [26](https://FAUST-BENCHOU.github.io/daily-arXiv-ai-enhanced/index.html?date=2026-06-18&paperId=2606.18650) 已提出 Hessian-free 的双层优化框架，但尚未与模型结构压缩（如 MoE 剪枝）协同考虑。本文创新点在于将数据选择与模型状态（如专家重要性）联合优化，实现训练效率与模型质量的协同提升。

#### 创新点四：归因驱动的结构化 MoE 压缩与训练联合优化

大多数现有 MoE 模型压缩方法在专家级别进行操作，通过移除整个专家或基于粗粒度重要性分数进行排序，忽略了专家内部通道级别的细粒度冗余，导致压缩预算分配不当 [16](https://FAUST-BENCHOU.github.io/daily-arXiv-ai-enhanced/index.html?date=2026-06-18&paperId=2606.18304)。少数现有方法开始探索通道级别的结构化剪枝，但通常将压缩视为训练后的独立阶段，未能利用训练过程中的梯度信息指导压缩决策 [16](https://FAUST-BENCHOU.github.io/daily-arXiv-ai-enhanced/index.html?date=2026-06-18&paperId=2606.18304)。为此，本文提出归因驱动的结构化 MoE 压缩与训练联合优化方法，将剪枝比率分配建模为通道分数覆盖最大化问题，并通过基于归因的近似方法高效求解，同时将压缩感知的梯度信号反馈到训练数据选择过程中。

- **创新类型：** 方法设计创新 + 约束处理创新
- **创新性判断：** 现有工作 [16](https://FAUST-BENCHOU.github.io/daily-arXiv-ai-enhanced/index.html?date=2026-06-18&paperId=2606.18304) 已提出基于归因的 MoE 结构化剪枝框架，但压缩与训练过程相互独立。本文创新点在于将压缩决策与训练数据选择联合优化，使压缩感知的梯度信号指导数据选择，同时使数据选择结果影响压缩策略。

### 论文方向三：面向多轮工具使用智能体的在线数据合成与训练优化

**拟定论文题目：** 面向多轮工具使用智能体的在线数据合成与训练优化方法

**论文核心问题：** 如何在多轮工具使用智能体的强化学习训练中，解决静态数据集信息样本快速耗尽的问题，实现持续的数据合成与高效的训练信号分配。

#### 创新点五：奖励方差驱动的在线数据合成方法

大多数现有方法依赖静态数据集进行多轮工具使用智能体的强化学习训练，随着训练进行，模型能力边界持续移动，静态数据集中信息样本（即模型成功与失败概率相当的样本）快速耗尽，导致梯度信号衰减 [30](https://FAUST-BENCHOU.github.io/daily-arXiv-ai-enhanced/index.html?date=2026-06-18&paperId=2606.19047)。少数现有方法引入在线数据合成，但通常需要额外的推理开销或人工标注来识别模型的能力边界，难以在训练过程中低成本地持续生成有效样本 [30](https://FAUST-BENCHOU.github.io/daily-arXiv-ai-enhanced/index.html?date=2026-06-18&paperId=2606.19047)。为此，本文提出奖励方差驱动的在线数据合成方法，利用 GRPO 训练中已计算的 rollout 奖励方差作为零成本的边界检测器，自动识别模型能力边界附近的样本，并通过技能对齐的重采样策略生成结构复杂度匹配的新样本。

- **创新类型：** 特征表示创新 + 方法设计创新
- **创新性判断：** 现有工作 [30](https://FAUST-BENCHOU.github.io/daily-arXiv-ai-enhanced/index.html?date=2026-06-18&paperId=2606.19047) 已提出奖励方差驱动的在线数据合成框架，但尚未与细粒度信用分配机制结合。本文创新点在于将数据合成与训练信号分配联合优化，使合成数据不仅匹配能力边界，还能为关键推理步骤提供更强的梯度信号。

#### 创新点六：自条件化信用分配与轨迹级训练信号优化

大多数现有 RLVR 方法（如 GRPO）对所有 token 分配均匀信用，浪费梯度在常规 token 上，而对关键推理步骤的信用不足，导致训练效率低下 [22](https://FAUST-BENCHOU.github.io/daily-arXiv-ai-enhanced/index.html?date=2026-06-18&paperId=2606.18810)。少数现有方法探索 token 级信用分配，但需要外部过程奖励模型、真实答案或教师模型等额外资源，限制了在纯 RLVR 设置中的适用性 [22](https://FAUST-BENCHOU.github.io/daily-arXiv-ai-enhanced/index.html?date=2026-06-18&paperId=2606.18810)。为此，本文提出自条件化信用分配方法，通过将模型条件化在其自身验证轨迹上，利用条件化分布与原始分布之间的可测量 per-token KL 散度作为信用信号，无需外部资源即可实现细粒度信用分配，并与在线数据合成方法协同，为合成样本中的关键步骤提供更强的梯度信号。

- **创新类型：** 方法设计创新 + 约束处理创新
- **创新性判断：** 现有工作 [22](https://FAUST-BENCHOU.github.io/daily-arXiv-ai-enhanced/index.html?date=2026-06-18&paperId=2606.18810) 已提出自条件化信用分配的理论框架，但尚未与在线数据合成方法结合。本文创新点在于将信用分配与数据合成联合设计，使合成数据的目标分布与信用分配机制对齐，实现训练信号的全链路优化。

创新点五解决“如何持续生成有效训练数据”，创新点六解决“如何为生成数据分配细粒度训练信号”。二者属于同一篇论文主题（多轮工具使用智能体的训练优化），但分别对应数据生成层面和训练信号分配层面，逻辑上形成递进：数据合成决定了训练样本的分布，信用分配决定了样本中哪些 token 获得更强的梯度信号。两者协同可实现比独立优化更好的训练效果。两者不存在重复。
