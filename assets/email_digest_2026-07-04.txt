## 论文方向一：LLM 推理性能建模与资源调优

**拟定论文题目：** 面向分阶段推理与硬件泛化的 LLM 服务性能建模与缓存压缩方法

**论文核心问题：** 如何在大语言模型推理服务中，同时解决跨硬件平台的性能预测泛化问题与长上下文场景下的 KV 缓存压缩效率问题，从而为资源调优提供统一的性能建模与缓存管理基础。

### 创新点一：跨硬件与模型泛化的推理功耗与延迟预测

大多数现有方法依赖对特定 GPU 和 LLM 组合的详尽性能剖析数据来构建功耗或延迟预测模型，当部署到未见过的硬件或模型时预测精度急剧下降，且需要昂贵的硬件访问权限 [1](https://FAUST-BENCHOU.github.io/daily-arXiv-ai-enhanced/index.html?date=2026-07-04&paperId=2607.02391)[3](https://FAUST-BENCHOU.github.io/daily-arXiv-ai-enhanced/index.html?date=2026-07-04&paperId=2607.01602)[7](https://FAUST-BENCHOU.github.io/daily-arXiv-ai-enhanced/index.html?date=2026-07-04&paperId=2607.01517)。少数现有方法尝试利用公开的 LLM 元数据和 GPU 规格构建轻量级预测模型，但它们在跨 GPU 和跨模型的留一法交叉验证中仍存在较大误差，且未能同时覆盖离线批处理与在线服务两种场景 [1](https://FAUST-BENCHOU.github.io/daily-arXiv-ai-enhanced/index.html?date=2026-07-04&paperId=2607.02391)[17](https://FAUST-BENCHOU.github.io/daily-arXiv-ai-enhanced/index.html?date=2026-07-04&paperId=2607.01590)。为此，本文提出一种仅依赖公开元数据的双模型预测框架，分别对平均 GPU 功耗和 token 间延迟进行建模，在 42 个开源 LLM 和 8 种 GPU 上的留一法验证中实现中位绝对百分比误差低于 10%，无需任何硬件访问或性能剖析 [1](https://FAUST-BENCHOU.github.io/daily-arXiv-ai-enhanced/index.html?date=2026-07-04&paperId=2607.02391)[17](https://FAUST-BENCHOU.github.io/daily-arXiv-ai-enhanced/index.html?date=2026-07-04&paperId=2607.01590)[20](https://FAUST-BENCHOU.github.io/daily-arXiv-ai-enhanced/index.html?date=2026-07-04&paperId=2607.01487)。

- **创新类型：** 问题建模创新 + 方法设计创新
- **创新性判断：** 该创新点针对现有功耗与延迟预测方法对未见硬件泛化能力不足的问题，提出仅依赖公开元数据的双模型方案，在文献池中 [1](https://FAUST-BENCHOU.github.io/daily-arXiv-ai-enhanced/index.html?date=2026-07-04&paperId=2607.02391) 是直接相关工作，[3](https://FAUST-BENCHOU.github.io/daily-arXiv-ai-enhanced/index.html?date=2026-07-04&paperId=2607.01602) 和 [7](https://FAUST-BENCHOU.github.io/daily-arXiv-ai-enhanced/index.html?date=2026-07-04&paperId=2607.01517) 从不同角度支撑了现有方法的局限性，[17](https://FAUST-BENCHOU.github.io/daily-arXiv-ai-enhanced/index.html?date=2026-07-04&paperId=2607.01590) 和 [20](https://FAUST-BENCHOU.github.io/daily-arXiv-ai-enhanced/index.html?date=2026-07-04&paperId=2607.01487) 提供了硬件感知和缩放定律方面的补充支撑。创新点明确，文献支撑充分。

### 创新点二：滑动窗口驱动的解码阶段 KV 缓存压缩

大多数现有 KV 缓存压缩方法采用阈值触发的压缩策略，在推理吞吐量提升有限的同时，可能完全移除序列中某些块的 KV 对，导致信息丢失和生成质量下降 [10](https://FAUST-BENCHOU.github.io/daily-arXiv-ai-enhanced/index.html?date=2026-07-04&paperId=2607.01237)[19](https://FAUST-BENCHOU.github.io/daily-arXiv-ai-enhanced/index.html?date=2026-07-04&paperId=2607.01831)[23](https://FAUST-BENCHOU.github.io/daily-arXiv-ai-enhanced/index.html?date=2026-07-04&paperId=2607.01520)。少数现有方法尝试保留固定大小的连续块或孤立 KV 对，但刚性边界无法适应任意 token 位置上的重要语义片段，且缺乏对因果掩码下压缩理论风险的系统刻画 [10](https://FAUST-BENCHOU.github.io/daily-arXiv-ai-enhanced/index.html?date=2026-07-04&paperId=2607.01237)[23](https://FAUST-BENCHOU.github.io/daily-arXiv-ai-enhanced/index.html?date=2026-07-04&paperId=2607.01520)[25](https://FAUST-BENCHOU.github.io/daily-arXiv-ai-enhanced/index.html?date=2026-07-04&paperId=2607.01775)。为此，本文提出一种滑动窗口驱动的解码时 KV 缓存压缩方法，仅对最近窗口内的 KV 对进行操作，结合渐进式量化传输机制，在保持推理精度的同时显著降低解码延迟和网络传输开销 [10](https://FAUST-BENCHOU.github.io/daily-arXiv-ai-enhanced/index.html?date=2026-07-04&paperId=2607.01237)[19](https://FAUST-BENCHOU.github.io/daily-arXiv-ai-enhanced/index.html?date=2026-07-04&paperId=2607.01831)[23](https://FAUST-BENCHOU.github.io/daily-arXiv-ai-enhanced/index.html?date=2026-07-04&paperId=2607.01520)。

- **创新类型：** 方法设计创新 + 约束处理创新
- **创新性判断：** 该创新点针对现有 KV 缓存压缩方法在信息保留和压缩策略上的双重不足，提出滑动窗口与渐进式量化相结合的方案。[10](https://FAUST-BENCHOU.github.io/daily-arXiv-ai-enhanced/index.html?date=2026-07-04&paperId=2607.01237) 是直接相关工作，[19](https://FAUST-BENCHOU.github.io/daily-arXiv-ai-enhanced/index.html?date=2026-07-04&paperId=2607.01831) 和 [23](https://FAUST-BENCHOU.github.io/daily-arXiv-ai-enhanced/index.html?date=2026-07-04&paperId=2607.01520) 分别从渐进式传输和理论风险角度提供了支撑。创新点与创新点一属于同一论文主题（推理性能优化），但分别解决预测建模和缓存压缩两个不同层面的问题，不存在重复。

## 论文方向二：LLM 智能体系统的安全性与可靠性保障

**拟定论文题目：** 面向 DevOps 与客户服务的 LLM 智能体动作边界监控与难度路由控制方法

**论文核心问题：** 如何在大语言模型智能体执行 DevOps 操作和客户服务任务时，有效检测和防止动作边界违规，并通过难度感知的路由控制机制在保持服务效率的同时降低操作风险。

### 创新点三：基于指令模糊度分解的动作边界违规检测

大多数现有 LLM 智能体基准测试主要关注任务完成率，忽略了在指令模糊但环境良性的情况下智能体可能执行超出预期范围的危险操作，导致生产事故 [13](https://FAUST-BENCHOU.github.io/daily-arXiv-ai-enhanced/index.html?date=2026-07-04&paperId=2607.01426)[26](https://FAUST-BENCHOU.github.io/daily-arXiv-ai-enhanced/index.html?date=2026-07-04&paperId=2607.02370)[30](https://FAUST-BENCHOU.github.io/daily-arXiv-ai-enhanced/index.html?date=2026-07-04&paperId=2607.02294)。少数现有方法开始构建安全边界基准，但通常将指令模糊度视为单一维度，未能区分意图清晰度、目标确定性和爆炸半径三个独立轴对智能体行为的不同影响 [30](https://FAUST-BENCHOU.github.io/daily-arXiv-ai-enhanced/index.html?date=2026-07-04&paperId=2607.02294)。为此，本文提出一种基于指令模糊度三维分解的动作边界违规检测方法，在 69 个任务族和 2208 个提示变体上系统评估智能体行为，实验表明 Claude Code、Codex 和 OpenCode 在模糊指令下存在显著的边界违规行为 [13](https://FAUST-BENCHOU.github.io/daily-arXiv-ai-enhanced/index.html?date=2026-07-04&paperId=2607.01426)[26](https://FAUST-BENCHOU.github.io/daily-arXiv-ai-enhanced/index.html?date=2026-07-04&paperId=2607.02370)[30](https://FAUST-BENCHOU.github.io/daily-arXiv-ai-enhanced/index.html?date=2026-07-04&paperId=2607.02294)。

- **创新类型：** 指标体系创新 + 评价方法创新
- **创新性判断：** 该创新点针对现有智能体安全评估中指令模糊度未被充分建模的问题，提出三维分解方法。[30](https://FAUST-BENCHOU.github.io/daily-arXiv-ai-enhanced/index.html?date=2026-07-04&paperId=2607.02294) 是直接相关工作，[13](https://FAUST-BENCHOU.github.io/daily-arXiv-ai-enhanced/index.html?date=2026-07-04&paperId=2607.01426) 和 [26](https://FAUST-BENCHOU.github.io/daily-arXiv-ai-enhanced/index.html?date=2026-07-04&paperId=2607.02370) 分别从客户服务和编译器优化角度支撑了智能体行为边界研究的重要性。创新点明确，文献支撑充分。

## 论文方向三：分布式训练与推理系统的弹性与效率

**拟定论文题目：** 面向异构工作负载的分布式训练与推理系统弹性调度与存储优化方法

### 创新点五：基于级联分解的异构视频模型训练编排

大多数现有文本到视频模型训练方法采用静态分桶策略将样本按分辨率或时长分组，在数据和序列并行等静态并行方案下难以随计算和数据量扩展，导致严重的工作负载不均衡和硬件利用率低下 [22](https://FAUST-BENCHOU.github.io/daily-arXiv-ai-enhanced/index.html?date=2026-07-04&paperId=2607.01701)[27](https://FAUST-BENCHOU.github.io/daily-arXiv-ai-enhanced/index.html?date=2026-07-04&paperId=2607.01486)[28](https://FAUST-BENCHOU.github.io/daily-arXiv-ai-enhanced/index.html?date=2026-07-04&paperId=2607.02324)。少数现有方法尝试将训练过程分解为细粒度计算单元，但现有级联编排框架在跨集群的时空协同优化方面仍存在同步开销大、扩展性受限的问题 [22](https://FAUST-BENCHOU.github.io/daily-arXiv-ai-enhanced/index.html?date=2026-07-04&paperId=2607.01701)[28](https://FAUST-BENCHOU.github.io/daily-arXiv-ai-enhanced/index.html?date=2026-07-04&paperId=2607.02324)。为此，本文提出一种基于级联分解的分布式训练编排框架，将训练过程分解为细粒度计算单元（级联），通过协调的时空优化实现跨集群的分布式执行和同步，在领先框架基础上将迭代时间降低高达 65%，并呈现正向扩展趋势 [22](https://FAUST-BENCHOU.github.io/daily-arXiv-ai-enhanced/index.html?date=2026-07-04&paperId=2607.01701)[27](https://FAUST-BENCHOU.github.io/daily-arXiv-ai-enhanced/index.html?date=2026-07-04&paperId=2607.01486)[28](https://FAUST-BENCHOU.github.io/daily-arXiv-ai-enhanced/index.html?date=2026-07-04&paperId=2607.02324)。
